〇 世界观总纲

本手册一切系统设计的根基。世界观由两大支柱构成：三级武学体系（力量如何成长）与社交驱动核心（玩家为何互动）。所有模块的玩法设计说明均以此为底色。

一、三级武学体系

武学以「境界 × 类别」构成正交体系：纵轴为三级境界（力量本源与定位不同），横轴为武学类别（拳/掌/腿/兵器，对应数据模型 art_type 枚举）。同一类别下，可依境界习得不同层次的技能。

第一级 · 基础篇 — 传统武学

根基：中国传统武学文化，物理学范畴（杠杆、冲量、重心）。力量本源：内力（character_statuses.mana）。涵盖：拳、掌、腿、兵器、内功、轻功、暗器、医术、毒术。定位：稳定可靠、消耗低、人人可练。风格：扎实稳健，如太极拳·揽雀尾、形意·崩拳、金钟罩。

第二级 · 科学篇 — 现代科学武技

根基：现代科学原理（生物力学、流体力学、声学、神经科学）。力量本源：体能 / 精力。涵盖：生物力学（寸劲/透劲/发劲）、流体力学（气刃/水刀）、声学（狮吼功/次声震荡）、神经反应（预判/闪避）。定位：技巧克制（破防/穿透/预判），可想象但不夸张脱离现实。风格：巧劲制胜，如动能贯拳、流体切割、神经预判。

第三级 · 玄学篇 — 自然力量

根基：元素魔法、自然力量（五行、气机、天地灵气）。力量本源：灵力。涵盖：五行术（金木水火土）、气机牵引、自然元素召唤。定位：范围爆发、高消耗高门槛，超脱物理但遵循自然法则。风格：天地之力，如炎龙焚天、寒冰结界、雷动九天。

二、社交驱动核心

这是本作与常规 MMO 最大的分野：所有玩家必须进行大量互动——互动推动剧情、互动积攒能量与资源。社交手段是核心玩法，而非附属系统。

社交动作→ 产出 · 情报 / 声望 / 人情 / 资源→ 推动剧情 + 修炼条件→ 力量成长→ 更高级社交场景
  • 情报喂任务：刺探情报产出任务线索、目标弱点，战斗与任务双线受益。
  • 资源反哺修炼：社交产出的声望/情谊兑换科学篇「参悟」与玄学篇「机缘」——高阶力量的门槛是社交深度而非纯氪金。
  • 剧情随互动推进：主线/支线进度与社交动作绑定（不刺探够情报无法触发关键剧情节点）。

五、平衡哲学 — 机制差异平衡

  • 三层定位不同而非碾压：基础稳、科学巧、玄学猛——不存在「高阶完全取代低阶」。
  • 强度梯度靠「门槛 + 消耗 + 冷却」三方共同平衡，防止数值膨胀。
  • 科学篇受「不夸张脱离现实」约束，其强大体现为机制（克制关系）而非数值。
  • 玄学篇的稀缺性由「机缘获取」保证——机缘来自社交深度（打听消息、揭榜、情谊），天然限制泛滥。

1.3 设计原则

  • 社交驱动：所有系统闭环到「互动 → 回报」循环，避免单机化养成。
  • 身份安全：账号/玩家/角色三层分离，双令牌隔离客户端与后台权限。
  • 全量审计：货币流水、物品变更、GM 操作、行为日志全覆盖，支撑反作弊与数据运营。
  • 运营可配：模板表（技能/任务/活动/掉落/公告）全部支持后台配置与热更。
  • 软删除：核心业务表均带 deleted_at，运营误删可恢复。

1.4 设计目标与里程碑

一句话目标：一款「社交是核心玩法」的 3D 武侠游戏——互动推动剧情、积攒能量与资源，社交手段即力量来源。

  • 设计目标：① 每个系统都闭环到「互动 → 回报」；② 社交货币（人情 / 帮贡 / 声望）只能通过社交获取（见 11.12）；③ 剧情随社交推进（见 7.6）；④ 社交建立率作为留存先行指标（见 13.8）。
  • 实现节奏：按「先基础社交设施（聊天 / 好友 / 帮派）→ 再核心社交玩法（情报 / 悬赏 / 关系）→ 后社交经济（担保 / 赊账 / 黑市）」三步推进，向目标靠近。
  • 验证口径：每日社交动作量、关系建立率、帮派活跃度、社交消费占比（见 12.5④）——数据驱动迭代。

第 2 章 · 账号与权限

账号体系是身份与安全的根基。策划视角关注：游客转化、封禁规则、后台人员权限划分。

2.1 账号类型

类型特点策划关注点
normal 普通用户名 + 密码注册主账号形态，可绑定手机/邮箱增强找回
guest 游客设备 ID 免注册进入转化漏斗起点；建议引导游客绑定正式账号，避免换设备丢档
wechat / google三方授权降低注册门槛（当前默认未开放）

2.2 封禁体系

auth_accounts 支持封禁原因（ban_reason）与封禁到期（ban_expire_at），到期自动解封；token_version 支持强制全员下线（版本号 +1，旧令牌全部失效），用于重大安全事件或版本更新。

2.3 双令牌权限

令牌对象接口域角色
Client JWT玩家/api/client/v1玩家身份（playerId）
Admin JWT运营人员/api/admin/v1super_admin / admin / operator / viewer
权限设计建议：viewer 仅可读（数据查看），operator 可操作模板/发奖，admin 可管理管理员与封禁，super_admin 为唯一超级账号；重要操作（发奖/封禁）必须留痕于 gm_operate_logs。

2.4 相关表

auth_accounts（账号）、admin_users（管理员）、account_login_logs（登录日志）、gm_operate_logs（GM 操作日志）。登录日志记录 IP/设备/地区，可支撑异地登录风控。

2.5 账号安全与社交（身份是社交信任的锚点）

  • 异地登录风控：登录日志（IP / 设备 / 地区，见 2.4）异常触发二次验证——账号被盗 = 社交关系被劫持（好友 / 帮派 / 交易都是目标）。
  • 安全密码：二次验证密码（见 3.1 safe_password_hash）用于交易 / 贵重操作——社交资产（礼物 / 红包 / 帮贡）同样需保护。
  • 绑定与找回：手机 / 邮箱绑定增强找回（见 2.1）——找回渠道是信任恢复的入口。
  • 冻结与申诉：可疑操作可冻结账号（临时），申诉流程恢复——与封禁（见 2.6）分级处置。

2.6 封禁与社交治理联动（处罚不止封号）

玩法定位：封禁是治理的最终手段（见 8.17 社交安全）——处罚要「打在社交关系上」而非只打在登录上，威慑才有社会性。

  • 分级处置：警告 → 禁言（见 14.4）→ 帮派除名（帮主执行，见 8.18）→ 限交易 → 封禁——按社交影响从小到大。
  • 社交后果：严重违规封禁时，社交资产同步处理（称号收回 / 帮派除名 / 榜单移除，见 10.6）——违规者被社会性除名。
  • 封禁公示：重大违规公示（江湖快报，见 8.10②）——公开治理建立公平感。
  • 申诉与修复：封禁到期后，信用分（见 8.15③）需通过社交行为修复——重新做人从社交做起。

2.7 运营权限与社交干预（GM 是江湖的「执剑人」）

  • 权限分级：viewer 只读 → operator 可操作模板 / 发奖 → admin 可管理管理员与封禁 → super_admin 唯一超级账号（见 2.3）。
  • 社交仲裁权：operator 级可执行社交仲裁（见 8.17②）、战斗调解（见 6.25）、活动回滚（见 13.6）——社交纠纷的终审在 GM。
  • 权限留痕：一切运营操作（含社交干预）入 gm_operate_logs（见 13.5）——执剑人也要被监督。

2.8 账号与身份认证（合规与防沉迷）

  • 实名认证：按发行地区合规要求接入实名认证（充值 / 部分玩法前置）。
  • 防沉迷：未成年时长 / 时段限制，与推送（见 14.6）联动——社交游戏也要守规矩。
  • 账号关联：SSO 单点（见 2.1 三方授权）未来接入时，账号体系已预留 token_version 全员下线能力（见 2.2）。

第 3 章 · 玩家与角色

「玩家」是现实身份（账号），「角色」是江湖身份（一个玩家可拥有多个角色，NPC 也复用角色模型）。本作的角色系统深度为武侠题材之最：属性、需求、资质、特长、关系、记忆、阵营、入魔、谍报、生存——每一层都服务于「社交驱动」。

3.1 玩家档案（players）

等级（level）、经验（exp）、VIP（vip_level / vip_exp）、累计充值（total_recharge）、在线状态。安全密码（safe_password_hash）用于交易/贵重操作的二次验证。

3.2 职业（characters.profession）

19 种职业决定身份底色与社交产出方向：农夫、樵夫、矿工（资源生产）、商人（经济）、守卫、将军（战斗）、工匠、铁匠（打造）、医生、药师（医疗）、教书、书生（知识）、乞丐（情报）、杀手、刺客（暗杀）、密探（谍报）、和尚（辅助）、贵族、小偷。

策划设计要点：职业是社交分工的天然纽带——玩家需要「找铁匠打装备、找药师求药、找密探买情报」，职业差异即社交需求的来源。建议职业特长与效率系数（character_specialties.efficiency）影响生产/修炼速度。

3.3 五大属性（character_attributes）

属性默认对应境界影响
strength 力量10基础篇拳脚/兵器物理威力近战输出、负重
speed 速度10基础篇轻功、科学篇神经反应出手顺序、闪避、移动

loyalty 忠诚度50—社交信用：背叛/背盟下降，影响委托与结义信任

战力（combat_power）由属性/技能/装备综合，是排行与匹配的依据。

3.4 需求系统（character_needs）— 社交驱动的底层引擎

参考马斯洛需求层次，角色拥有五类需求（默认 50）：

需求满足方式（策划可配）
survival 生存食物（character_resources.food）、住所
safety 安全阵营庇护、保镖、安全区
belonging 归属帮派、结义、师徒——必须社交

actualization 自我实现武学巅峰、玄学机缘、剧情成就
核心玩法连接：需求得不到满足 → 角色状态（生存/安全）下降 → 需要求助帮派/好友；归属与尊重需求只能通过社交动作满足——这是「社交是核心玩法」在数值层的硬保证。

3.5 资质与特长

  • 资质（character_qualifications）：默认 2，决定武学成长上限；消耗性资质（is_consumable）作为高价值奖励投放。
  • 特长（character_specialties）：主特长 + 副特长列表 + 效率系数，影响对应职业行为的产出速度。

3.6 关系网络（character_relationships + character_memories）

关系表记录角色间的好感度（favorability）、关系等级（stranger 陌生 → friend 友人 → confidant 知己 → enemy 仇敌）、关系事件历史与剧情触发钩子。记忆表承载长期社交记忆：雇主、互动、秘密、朋友、仇敌、传闻。

策划设计要点：记忆是「社交即剧情」的数据底座——NPC 与玩家记住你帮过/害过谁，触发差异化剧情与隐藏任务；秘密与传闻（secrets/rumors）是情报交易的货品。

3.7 阵营（character_factions）

正（righteous）/ 邪（evil）/ 中立（neutral）三阵营，默认中立。阵营等级（默认 5）与称号（faction_title），阵营间好感度（faction_relations）影响组队/交易/攻防关系。入魔会改变阵营偏向（向邪偏移），猎杀与被猎杀是阵营冲突的日常形态。

3.8 入魔（character_darkened）— 高风险高回报

玩法定位：高风险高回报的角色成长分支，承担「长线养成 + 玩家对抗」双重职责。

  • 核心循环：角色选择入魔 → 战力 ×1.5（power_boost 默认 1.5）→ 获得魔名（darkened_name，隐藏原身份）→ 成为他人猎杀目标（hunting_target）→ 可洗白回归或维持入魔。
  • 设计意图：「强但不安全」——数值鼓励入魔，身份隐藏带来 PVP 博弈，猎杀机制形成玩家间对立目标。
  • 可配置项：战力倍率、入魔原因文案、猎杀目标绑定。
  • 系统联动：入魔 ↔ 排行榜（战力加成影响排位）↔ 阵营 ↔ 社交（魔名影响好友识别与信任）。
  • 平衡考量：1.5 倍若叠加装备/技能易膨胀，需限制入魔后成长曲线；猎杀过于频繁会导致对抗疲劳。

3.9 谍报（character_espionages）— 情报社交的核心

玩法定位：情报是社交驱动的「硬通货」，谍报系统是五大社交动作之一「刺探情报」的载体。

  • 能力开关：can_spy（可刺探）、can_infiltrate（可渗透），谍报等级（espionage_level）决定成功率与情报价值。
  • 当前谍报任务（current_mission）+ 伪装身份（disguise）——渗透敌方阵营/帮派窃取情报。
  • 产出：目标弱点（供战斗克制）、剧情线索（供任务）、秘密（供交易）。

3.10 生存消耗（character_consumptions）

每日食物消耗（默认 9），低于最低食物线（默认 3）进入饥饿；连续饥饿（hunger_days）恶化状态：well_fed 饱食 → normal 正常 → hungry 饥饿 → starving 濒死 → dead 饿死。离线也会结算（offline 模块），形成「回归后处理生计」的日常钩子。

3.11 状态 / 位置 / 资源 / 伙伴 / 特殊效果

  • 状态（character_statuses）：气血 health、内力 mana（基础篇消耗）、财富 wealth、声望 reputation（社交核心）、生死（江湖死亡制：is_alive / death_cause / death_date）、世代 season（江湖传承）、家族 family（继承/复仇）。
  • 位置（character_locations）：地图/地块/区域/坐标/室内，路径历史用于行为分析。
  • 资源（character_resources）：食物/木材/铁/草药/金银——生存与生产原料。
  • 伙伴（character_companions）：跟随、陪伴时长、牺牲机制（sacrifice_used / last_words，剧情向）。
  • 特殊效果（character_special_effects）：剧情/活动授予的持久效果（代码识别 code + 参数 params）。

3.12 角色形象与外观（社交展示的第一印象）

玩法定位：外观是「被看见」的第一媒介——同场景玩家靠形象认人，外观即社交名片（见 5.6 名片联动）。

  • 形象数据：捏脸 / 时装 / 挂件（外观系统数据入角色档案），装备「展示模式」叠加稀有度光效（见 4.6③）。
  • 称号显示：头顶称号（声望 / 成就 / 榜单，见 8.16①）——一屏之内立人设。
  • 外观收集：时装图鉴（收集奖励，见 4.6 炫耀经济）——收集是展示的燃料。
  • 外观交易：可交易外观进入交易 / 拍卖（见 11 章）——美也是经济。

3.13 角色叙事身份（江湖名号与人设）

玩法定位：江湖身份是社交叙事层——名字之外，还有名号、诗号、传记。

  • 江湖名号：系统称号（如「铁掌镇河」）+ 自定义诗号（见 14.2② 自定义诗号）——身份可自定义。
  • 江湖传记：角色经历自动生成传记（大事记：结义 / 复仇 / 榜单）——社交史即传记。
  • 魔名：入魔后获得隐藏原身份的魔名（见 3.8）——身份可隐藏，叙事更刺激。
  • 世代与家族：江湖传承世代（season）+ 家族（family）——身份可继承（见 3.11 状态）——「他爹是当年那位」是顶级社交谈资。

第 4 章 · 背包与道具

道具是经济与社交的载体：可交易、可掉落、可绑定，全部变更留痕。

4.1 物品模板（item_templates）

4.2 背包（inventory_items）

按玩家持有（player_id），含数量、格子索引、绑定状态（bind_status）、过期时间（限时道具）、附加属性（extra_attrs：随机词条/强化值）。

4.3 装备（character_equipment）

五个槽位：weapon 武器 / helmet 头盔 / armor 护甲 / boots 靴子 / accessory 饰品。装备槽位唯一（同一角色同一槽位只能一件），通过 inventory_item_id 关联背包物品。

4.4 变更审计（player_item_change_logs）

每次获得/移除/交易/销毁都记录：变更类型、数量、操作追踪（op_trace）、变更后余额。与货币流水（transactions）构成双轨审计，支撑反作弊与问题追溯。

4.5 道具的社交属性（物品不只是数值）

玩法定位：道具是「社交的载体」——外观被看见、礼物表心意、限定有话题，物品模板需要配置社交标签。

① 社交标签字段（item_templates 扩展）

② 道具叙事

限定道具带「来处」（产出活动 / 事件，见第 9 章），成为江湖谈资——物品描述里的一句来处，就是玩家的社交开场白。

4.6 稀有度与炫耀经济（展示类社交的底座）

玩法定位：稀有度是「被看见」的货币——越稀有越要秀，炫耀动作（见 8.16）依赖稀有度体系供给素材。

  • 梯度深化（承接 4.1）：common / rare / epic / legendary 四档外观特效分级——同款装备 legendary 有专属光效。
  • 全服播报：获得 legendary 触发全服广播（展示类，见 8.16），上茶楼头条（见 8.10②）。
  • 套装与称号：集齐套装解锁展示称号（见 8.16①），套装图鉴入个人主页（见 8.16③ 观战主页）。
  • 炫耀橱窗：装备栏可设「展示模式」，同场景玩家可见（名片联动，见 5.6）——装备是行走的名片。

4.7 礼物道具体系（关系系统的载体）

玩法定位：礼物是「关系类」社交动作的实体载体——心意通过物品传递，好感度通过礼物计量（见 8.7）。

  • 礼物模板：礼物道具带好感度权重（gift_weight，见 4.5①），送礼记录入好感度流水（见 8.7 好感度阶段）。
  • 礼物场景：日常送礼（相识解锁，见 8.7）、节日限定礼物（活动产出，见第 9 章）、婚礼彩礼（见 8.7④）。
  • 红包道具（深化 8.13②）：金币 / 钻石红包封装为道具，可群发（帮派 / 队伍 / 全场景）——红包是「馈赠类」社交动作的快捷载体。
  • 防刷：每日送礼上限（见 8.7）+ 礼物价值封顶，防止互刷好感。

4.8 限定与绝版道具（稀缺性社交）

玩法定位：稀缺制造话题——限定让活动有吸引力，绝版让老玩家有身份，存量流通让交易有价值（见第 11 章）。

  • 限定道具：活动限定产出（见第 9 章），错过等复刻——复刻由社区投票决定（社区运营，见 13.7）。
  • 绝版道具：停产后存量为王，可交易（见第 11 章）保值——绝版是「老玩家身份」的社交勋章。
  • 防通胀：绑定（bind_type，见 4.1）与限量（max_participants，见 9.1）双保险，控制存量。
  • 绝版行情：茶楼物价指数（见 11.8）反映绝版价格曲线——绝版是社交资产也是投资品。

4.9 背包管理与社交空间（整理也是社交）

玩法定位：背包不只是仓库——共享、展示、转交让「持有」变成社交关系的一部分。

  • 背包与仓库：容量可扩充（扩充道具），仓库格解锁——收纳本身是长期目标。
  • 帮派仓库：共享材料（帮贡兑换，见 8.22），帮派建设用料集中存放（见 8.19）——个人持有参与集体建设。
  • 家园展示柜：收藏品摆入家园展示柜（见 8.16② 家园拜访可见）——收藏是「被参观」的社交资产。
  • 赠予与转交：好友间道具转交（限次数防刷）、NPC 传信委托（见 5.11）——道具在关系中流动。
  • 一键整理：背包一键整理、套装方案保存（联动 6.12 数值成长）——整理效率让玩家更多时间在场景社交。

4.10 装备数值平衡策略（强化有度，迭代有序）

玩法定位：装备是战力载体也是保值资产——平衡目标：强化有上限、迭代有节奏、老装备有价值、数值不碾压。

  • 强化上限：强化等级封顶（默认 +10），每级加成递减（+9 级收益衰减 30%）——防滚雪球，逼玩家横向配装而非纵向死磕。
  • 耐久与消耗：装备耐久随战斗消耗（见 4.3），修复消耗材料——装备有生命周期，持续回收经济存量（呼应 5.21⑤ 回收泵）。
  • 迭代节奏：新装备阶梯投放（版本 / 活动 / 副本），替代曲线与成长曲线对齐（见 6.12）——老装备降价入次级市场（见 11.8 物价），换代即话题，旧装即馈赠（见 8.13 送礼）。
  • 产出-消耗平衡：装备产出（打造 / 掉落）与耐久消耗、强化材料消耗挂钩（见 5.21② 消耗锚点）——装备是消耗泵，不是通胀源。
  • 防碾压护栏：高装等对低装等衰减（境界差衰减同思路，见 6.26②）——装备碾压有上限，操作与配合永远有空间。

第 5 章 · 世界与场景

世界是社交的舞台。区域划分、NPC 分布、触发器编排，决定玩家在何处相遇、以何种方式互动。

5.1 场景（scenes）

场景类型（town 城镇 / wild 野外 / dungeon 副本 / arena 擂台等）、地图资源、尺寸、图层配置、刷新规则、触发器组、进入等级（min_level）、人数上限（max_players）。城镇是社交主舞台，野外是资源与对抗，副本/擂台是协作与竞技。

5.2 区域（character_locations.region）

central_city 主城 / black_forest 黑森林 / iron_mine 铁矿 / gold_plain 金原 / wilderness 荒野。区域决定资源产出与安全等级——主城安全区承载摆摊/茶馆/擂台，野外承载采集与猎杀。

5.5 城镇社交空间布局（社交场景地图）

玩法定位：主城不是装饰性场景，而是按社交动线规划的「功能舞台」——每个功能区承载特定社交动作，动线闭环让玩家「逛街一圈完成一天社交」。

5.6 场景内社交行为基础设施

玩法定位：场景要承载社交，先要有「看见彼此、喊得到人」的基础设施。

  • 附近频道与区域广播：同场景玩家互相可见（名片 / 手势：作揖 / 挑衅 / 招手 / 鼓掌）；区域广播（附近频道）与世界频道（见 8.1）分层，避免刷屏。
  • 场景聚集事件：世界 BOSS 刷出 / 帮战集合 / 庙会开场自动生成中心广场集合点，一键传送召集（消耗少量资源，防滥用）。
  • 偶遇机制：场景移动概率触发偶遇（路人甲 / 行脚商 / 行脚僧，见 8.12①），让「赶路」也带社交期待。
  • 场景分流策略：主城高峰期镜像分流（按分线编号），同队 / 同帮玩家强制同线，避免「约好见面却不同线」。

5.7 野外与对抗场景的社交

玩法定位：野外是「竞争与协作并存」的社交场——采集抢点、组队猎杀、据点占领、镖线对峙，对抗本身就制造关系。

  • 采集区：同资源点多人可采（组队共享采集加成）；采集中可被友好「切磋挑战」，输者让点——把资源竞争变成社交博弈而非纯 PK。
  • 猎杀区（红名出没地带）：玩家组队狩猎入魔者（见 8.9③）；猎杀组队是「协作类」社交动作的野外版本，猎杀成功全场景播报。
  • 帮派资源点：野外据点可被帮派占领（见 8.8），占领期内产出帮派资金，敌对帮派可发起争夺战——野外场景承载帮派对抗。
  • 镖线对峙：运镖路线跨场景（见 8.9①），沿途固定伏击区是「护送队 vs 劫镖团伙」的天然对峙舞台；安全区 / 非安全区标注清晰，红名不可入安全区。

5.8 副本与秘境场景的社交

玩法定位：副本入口是「组队等待的社交场景」，副本内是「分工协作的验证场」——秘境把「凑人」与「配合」都社交化。

  • 秘境入口聚集：副本入口设「集结区」，支持组队自动匹配（见 8.14①）与等待互动（闲聊 / 切磋热身 / 临时搭伙）。
  • 副本内分工：高难副本 BOSS 机制分工（见 6.20②）+ 阵法配合（见 6.19①），验证日常社交经营的默契。
  • 首通与排行：副本首通全服广播（展示类），周通关榜并入排行（见第 10 章）——副本成就是「被看见」的勋章。
  • 帮派 / 家园副本：帮派副本（见 8.8）与家园练功桩（见 8.16②）是私域协作场景，成员共玩空间。

5.10 场景内互动动作集（手势 / 坐席 / 装饰）

玩法定位：场景要「玩得起来」，先有丰富的就地互动——手势打招呼只是起点，坐下、留言、围火才是「在场感」的来源。

① 手势与表情动作（深化 5.6）

  • 通用：作揖 / 鼓掌 / 招手 / 挑衅 / 拱手 / 抱拳——快键触发，附近可见；挑衅带颜面后果（见 6.23）。
  • 仪式动作：结拜（见 8.7②）、侠侣成礼（见 8.7④）有专属场景动作（同场景可围观）。

② 坐席系统（坐下来才社交）

  • 茶楼落座（听书见 8.10②）、客栈雅间（组队 / 离线挂机见 6.17③）、长凳闲聊——「坐下」是场景社交仪式，坐席有占用状态，同席自动进附近频道。
  • 野外篝火 / 火塘：夜间聚集点，围火触发「夜话」闲聊事件（轻量情报产出，呼应 8.6 E 级街谈巷议）。

③ 场景装饰互动

  • 祈福墙（庙会，见 8.10③）可留言祈福（展示类）；客栈留言板可留话（离线传话）；涂鸦墙（限时活动）可创作。

玩法定位：NPC 是场景与系统之间的「社交中介」——情报、牵线、委托、传话都通过 NPC 发生，NPC 让社交有「人物」。

5.12 场景动态氛围（时段 / 天气 / 节庆）

玩法定位：场景氛围随时段、天气、节庆流动——不同时间去同一个地方，社交内容不同，玩家因此「选时间去场景」。

  • 昼夜循环：白天摆摊街最热闹（见 11.4）、夜晚茶楼说书开场（见 8.10②）、深夜客栈静——时段决定场景社交重心。
  • 天气事件：雨雪天气茶馆避雨聚集（临时社交场）、野外采集效率变化；节日氛围（中秋灯会 / 春节庙会，见 8.10③）临时场景装饰。
  • 场景氛围标识：热闹 / 肃杀 / 宁静三档氛围影响区域广播范围（见 5.6）与偶遇概率（见 5.6）——氛围是可感知、可利用的。
  • 活跃提醒：运营可配置「场景活跃」推送（人少场景的组队召集，见 8.14① 自动匹配联动），疏导人流、盘活冷门地图。

5.13 场景安全与红名社交（冲突场景细则）

玩法定位：安全区不是「无社交」，而是「换一种方式社交」——挑衅、决斗、执法都在安全规则内发生，冲突被设计成仪式而非滥杀。

  • 安全区规则：禁 PK 但可挑衅（发起决斗邀请，见 6.10⑨ 点到为止 / 生死斗）；红名不可入安全区（见 5.7），被通缉者在野外暴露。
  • 决斗流程：场景内发起决斗（双方同意）→ 围观（见 6.10⑧ 助威与气势）→ 结算入 combat_logs；决斗是「对抗类」社交动作的受控形态。
  • 场景仇恨记忆：在被击杀 / 击杀过人的场景留痕（见 8.15② 恩怨），回该场景触发仇人遭遇提醒——场景是恩怨的「老地方」。
  • 场景执法：官府捕快巡逻（红名驱逐，见 8.9②）、悬赏公示栏（通缉信息全场景可见）——执法本身是公开的社交剧场。

5.14 场景与叙事结合（社交剧情舞台）

玩法定位：场景是剧情的「舞台」——NPC 大事件、玩家自办活动、场景留痕，让地图承载故事、故事反哺人气。

  • 场景剧情舞台：剧情事件在特定场景上演（婚礼 / 庆典 / 灭门惨案现场），玩家可围观、参与、传播（见 8.10② 快报）——场景事件即社交话题。
  • 玩家自办活动：玩家可租用场景举办活动（见 8.16 展示类）：侠侣婚礼巡游、生日宴、帮派庆典（见 8.8① 宴会）——玩家把场景变成自己的舞台。
  • 场景留痕：留言（见 5.10③ 留言板）、纪念碑、玩家雕像（声望荣誉，见 8.15①）——「到此一游」成为长期社交资产。
  • 场景故事线：每张地图一条主线剧情（任务链，见第 7 章），社交条件解锁（见 5.9③）——地图不是无限刷怪场，而是有起承转合的叙事空间。

5.15 场景物件互动（人 · 事 · 物的三种用法）

玩法定位：场景里的每一棵树、一口井、一张床都不是背景板——「一物三用」：每个可互动物件至少绑定一个生存动作、一个玩法动作、一个社交动作。

  • 大树藏身：藏身是「观察别人」的入口——树上俯察、树影窃听（见 8.6 情报生态）——一棵树就是一张情报网（谍报联动，见 3.9）。
  • 树下烧火：篝火围坐触发轻情报夜话（见 5.10②）——取暖之外，火光聚人，人是火的燃料。
  • 床与客栈：留宿触发夜宿剧情与同宿偶遇——睡一觉也能结一段缘。
  • 告示板：全图信息中枢——贴广告、揭榜、看通缉都在这，是场景的「广场」（联动 14.9 话题）。
  • 灶台分享：做饭分食是情义（见 8.13③）——一碗热汤就是人情。

5.16 场景机关与谜题（物是死的，事是活的）

玩法定位：场景不只有「摸一下」的物件，还有「动脑动手」的机关——机关是「事」，是玩家协作与智斗的舞台。

  • 机关类型：机关石门（开锁 / 推石）、棋盘残局（解谜 / 对弈）、密道入口（藏身 / 逃命路线，见 5.15① 大树藏身同思路）、机关陷阱（触发 / 破除）、瀑布暗洞（奇遇入口，见 6.16 机缘）。
  • 机关社交：多人机关需配合（一人踩位一人触发——站位即协作，见 6.19 阵法同思路）；破解机关全场景广播（展示，见 8.16①）——「破机关的队伍」是谈资。
  • 机关情报：机关解法可打听（情报货品，见 8.6）——知道解法的人，靠知识赚钱。
  • 机关谜题掉落：解谜产出宝箱（组队分赃仪式，见 6.24）——事成之后的分配，又是一场社交。

5.17 场景生物与坐骑互动（万物有灵）

玩法定位：场景里的活物不是装饰——马匹载人、信鸽传书、宠物陪伴、动物奇遇，让「物」活起来。

  • 坐骑：马匹（骑乘代步、驿站换马，见 5.20③）、马车（多人同乘——同路即同聊）。
  • 信鸽传书：书信经信鸽送达（异步社交，见 14.6 离线留言同框架）——飞鸽传书是武侠味的消息推送。
  • 宠物伙伴：跟随宠物（陪伴 + 互动，见 3.11 伙伴 companion）——宠物是社交破冰话题（「你这猫真俊」）。
  • 动物奇遇：灵兽引路（触发奇遇，见 6.16）、动物救助（善举入声望，见 8.15①）——救一只鹿，可能结一段缘。

5.18 场景微型玩法（街头小游戏）

玩法定位：每个街角都可能有「一局」——小游戏是低门槛、高频次的社交场景。

  • 小游戏清单：垂钓（河塘点位）、对弈（棋盘摊位）、投壶 / 射箭摊（庙会，见 8.10③）、斗蛐蛐（赌彩头）、套圈（奖品兑换）——一图多摊，逛街即娱乐。
  • 围观经济：小游戏可围观下注（彩头，见 11.3 议价同思路）——玩的人有输赢，看的人有话题。
  • 摊主身份：玩家可摆小游戏摊（摆摊升级，见 11.4）——开一局，交一友。
  • 小游戏排行：垂钓大师 / 棋圣等图内小榜（见 10 章排行框架）——街角也有荣誉。

5.19 场景资源点与生活技能（田、矿、渔、酿）

玩法定位：资源点是生产链的起点，也是职业玩家（见 3.2）的「地盘」——生产本身是社交分工。

  • 资源点位：药草园（药师）、矿脉（矿工）、渔点（渔夫）、农田（农夫）、酒窖（酿造）——按职业效率产出（见 3.2 特长效率）。
  • 点位的社交性：资源点共用（让点 / 抢点）、合作采集（帮派资源田，见 8.19 驻地）、定期刷新（蹲点相遇成熟人）——同锄一块地，就是半个熟人。
  • 产出即社交：药材供丹药（见 6.18）、食材供灶台（见 5.15②）、木材供家具（见 5.15③）——生产链末端全是社交场景。
  • 特产经济：区域特产（见 11.10 跑商）——你的田，是别人的商路。

5.20 场景导航与地标互动（走路也是社交）

玩法定位：地图不只有「传送点」——路牌、瞭望塔、驿站、地标让「赶路」本身产生相遇与话题。

  • 路牌：查看地图信息、贴留言（见 5.10③）——岔路口是「等人」与「偶遇」的默认地点。
  • 瞭望塔：登塔解锁视野（发现资源点 / 事件）、放哨（帮派协作，见 8.20）——塔上看得远，也容易被看见。
  • 驿站：马匹换乘、组队同程（见 8.14）、跑商起终点（见 11.10）——驿站是流动人口的聚集点。
  • 地标打卡：风景地标（观景台 / 名胜）打卡合影（展示，见 8.16）——「到此一游」是社交履历。
  • 地标事件：地标定时事件（见 5.9② 世界事件）——地标是事件的发生地，事件是地标的广告。

5.21 场景资源能量平衡策略（生态 × 经济 × 社交）

玩法定位：资源点不是「无限挖的矿」——四类资源（山川湖泊 / 农田 / 林木 / 矿产）各有供给节奏与消耗锚点，平衡目标是：供给跟上消耗、争夺带来社交、富余不泛滥、稀缺不绝望。

② 产能与消耗平衡（供需对照）

  • 食物基准：生存消耗每日 9、下限 3（见 3.10）——农田 / 湖泊供给需覆盖全服消耗基线，缺口由「产量 × 效率」参数调节（见 3.2 职业效率）。
  • 消耗锚点：每种资源至少绑定一个「消耗泵」（食物→生存、木材→家具/建筑、矿石→装备/锻造、药材→丹药）——无消耗锚点的资源会贬值，有锚点的资源才保值。
  • 供需比值：建议维持「日产量 ≈ 日消耗 × 1.2」（20% 富余）——富余太多物价崩（见 11.8），富余太少资源焦虑。

③ 动态平衡机制（生态是活的）

  • 枯竭与丰饶：过度采伐触发林地退化（产量 -50% 持续 24h）；休渔/休矿期促进恢复（产量 +25%）——生态惩罚引导玩家自我节制。
  • 价格联动：资源稀缺度计入茶楼物价行情（见 11.8）——稀缺自动涨价、泛滥自动降价，供需自动调节。
  • 密度调节：资源点产量随该区域活跃人数动态调节（见 5.6 分流同框架）——人多保供给、人少防过剩。
  • 事件注入：世界事件（商队投放 / 官府收购，见 11.8③）临时注入或回收资源——运营可干预平衡。

④ 玩家间分配平衡（争夺是社交，独占是原罪）

  • 采集上限：单人单点日采集上限（默认 50 次）+ 收益递减（第 30 次后效率 -30%）——防垄断、逼分工。
  • 点位的社交分配：共用资源点鼓励「让点」（让点 + 颜面，见 6.23）、争夺资源点形成竞争（PVP 区域，见 5.7③ 帮派资源点）；占而不采会被人记住（仇人录，见 8.15②）。
  • 帮派配额：帮派资源田按职位配额（见 8.19 驻地）——集体资源内部公平，贡献多者份额高（见 8.8① 帮贡）。
  • 防工作室：单账号收益上限 + 行为审计（见 4.4 变更审计、13.3 行为日志）——资源产出异常波动当天可见（见 C.4 业务告警）。

⑤ 经济注入与回收（防通胀闭环）

  • 加工链：原料 → 半成品 → 成品（矿→铁锭→装备），每级加工产生损耗与工时——资源在加工链中转化为价值，而非直接变现。
  • 回收泵：装备耐久消耗（见 4.3）、食物腐坏、家具损耗——资源型产物有生命周期，持续从经济中抽走存量。
  • 绑定兜底：高价值资源产物绑定（见 4.1 bind_type）限制倒卖——资源价值留在玩家身上，而非流入投机。

⑥ 防挂机与反通胀护栏（活跃才有产出）

  • 离线不产：资源点离线不产出（离线挂机仅限练功房，见 6.17③）——资源是「在线社交的奖励」，不是挂机收益。
  • 效率递减：连续采集效率递减（防 24h 挂机脚本），刷新周期内换点/休息最优。
  • 数值护栏：全服日产量硬上限（稀有矿），达到上限后当日报警并停采（运营可配，见 13.2）——稀缺资源天生限量，限量即价值。
  • 审计闭环：产出 / 交易 / 消耗全量流水（见 4.4、11.12 多币种审计）——平衡是否失效，数据当天说话（见 13.4）。

兼修规则：同角色可兼修多类武学（武学熟练等级独立成长，见 6.2），但属性点分散导致单类强度下降——「博而不精 vs 专精一艺」的取舍，天然形成战斗风格分化（联动 6.5）。

  • 参悟券：社交积分兑换 / 每日社交任务产出——科学篇晋升与技能升级的硬通货（呼应世界观总纲「高阶力量的门槛是社交深度」）。

6.10 战斗机制细则（命中 / 暴击 / 克制 / 连击）

① 命中与闪避

命中率 = 基础 90% + 命中修正 − 目标闪避；科学篇「预判」类技能可临时提升闪避（见 6.7②），轻功类位移可规避指向性技能。

② 暴击

暴击率 × 暴击伤害（默认 1.5 倍）。玄学篇暴击率上限更高但基础命中更低（高收益高风险），与科学篇「稳定技巧」形成反差。

③ 破防与穿透

破防 = 百分比无视防御（如寸劲·透 50%）；穿透 = 无视护体/护盾。两者是科学篇克制「高防坦克」的手段，避免纯堆防御无敌。

④ 五行克制

金→木→土→水→火→金：克制 +20% 伤害，被克 −10%。玄学篇技能天然带五行属性；基础/科学篇可通过「五行附魔」临时切换属性（消耗材料），把克制从玄学专属扩展为全员博弈。

⑤ 机制克制（三层剪刀石头布）

基础稳（持续消耗拖垮爆发）克 玄学猛（高冷却空窗期）；科学巧（破防/预判）克 基础稳（站桩输出）；玄学爆发（短窗口秒杀）克 科学巧（脆皮技巧）——防止单一境界通吃，落实「机制差异平衡」哲学。

⑥ 连击与合击

同武学类别连续施放触发连击加成（第 3 连 +20%）；组队战斗中，结义技 / 情侣技（见 8.7）触发同步合击（详见 6.19②）——战斗奖励「一起玩」。

⑦ 情报弱点（社交 → 战斗直连）

刺探 / 窃听得到的目标弱点情报（见 8.6，B 级及以上）可在战斗中「针对弱点」一次性消耗：触发易伤 +15% / 破防 +20%。目标可花费资源「清除自身弱点情报」反制（反侦察）。这是「情报喂战斗」的直接落地——战斗准备从「组队刷装」扩展为「组队 + 刺探」，让谍报成为高难度战斗的必修课。

⑧ 助威与气势（围观 → 战斗加成）

  • 观战者喝彩 / 打赏累计「气势值」，战斗方获得至多 +10% 攻防（士气）；帮战主场 / 擂台主场的可累计上限更高。
  • 气势需要真实观战行为累计（场景到场 + 交互），防止脚本刷气势。
  • 被围观也是风险：通缉犯被围观时暴露行踪（见 8.9），围观系统同时服务「助威」与「曝光」双向。

⑨ 战斗模式（点到为止 / 生死斗）

  • 切磋 / 恩怨战（见 6.21①）开战前由发起方声明模式：点到为止（胜负即止，无死亡惩罚，败者付彩头或认输，双方好感度不变甚至微升）或 生死斗（可致死，掉经验 / 部分掉落，结仇加深见 8.15②）。
  • 系统默认点到为止；生死斗需双方同意（红名 / 通缉者除外，强制生死斗）——把「要不要下死手」变成社交决策，避免无差别杀戮。
  • 模式影响结算：点到为止记录 combat_logs 胜负即可；生死斗触发死亡处理——遗体可由好友收敛（收敛者获人情，见 8.13③），死亡损失与社交悼念形成「生死有江湖」的叙事。

⑩ 社交化解动作（谈判 / 求饶 / 劝降）

  • 战斗中可发起社交化解：谈判（付代价止战）、求饶（降颜面 / 付彩头换生存）、劝降（PVE 对 NPC / 入魔者，成功率受声望与好感影响）。
  • 化解成功率 = 基础 + 声望修正 + 好感修正 − 目标愤怒度；被劝降的入魔者（见 8.9③）可由「说和人」净化而非击杀（呼应 6.25）。
  • 化解失败进入「恼怒」状态（对方攻击 +10%，短暂），防止无脑求饶刷生存——嘴遁也是要底子的。

6.12 数值成长与平衡校验

① 成长曲线建议

  • 每级属性 +2%；技能伤害随 min_level 分段：1-30 / 31-60 / 61+ 每档 ×1.8。
  • 三条资源线独立：内力（被动回复 + 药品）、体能（休息 + 食物）、灵力（灵石 + 冥想）——防止单资源吃遍三层，各自形成消耗经济。

② 平衡校验清单（上线前自查）

  • 同级同装备下，三层流派 DPS 曲线应在 ±15% 内接近——差异体现在机制（克制/爆发/控制）而非数值。
  • PVP 单挑时长 30-90s；帮战团战 10 分钟内分出胜负。
  • 高境界打低境界伤害衰减（境界差 ≥2 时 ±30% 调整），保护低阶玩家体验，防碾压劝退。

6.13 战斗社交经济学（借力 / 助战能量 / 人情闭环）

玩法定位：把「社交关系」变成可消耗、可积累的战斗资源——战斗不再是孤立的数值对撞，而是日常社交经营的变现场。

① 助战能量（并肩成长）

  • 每场助战成功双方获得「并肩」标记，累计提升组队默契值（见 8.14②）；助战还能触发「并肩成就」（见 7.3 社交类成就）。
  • 助战不消耗被助者的任何资源，只消耗助战者时间——「付出时间换人情」，社交参与本身成为可再生资源。

② 战斗人情闭环

求助→ 消耗人情值→ 援助 · 获得人情值→ 借力 · 再消耗→ 再求助
  • 求助消耗人情（见 8.13③）→ 助战者获得人情 → 借力消耗人情——人情是战斗协作的唯一硬通货，越乐于助人，越能在关键时刻获得支援。
  • 人情值每日有获取上限（防互刷），但求助侧消耗不设上限（鼓励开口求助，降低卡关挫败）。

③ 战斗声望

战斗表现（连击数 / 救场次数 / 助战次数 / 胜率）折算为江湖声望（见 8.15）：救场与助战权重高于单纯击杀——「会打架」不如「会救场」有声望，从数值上引导协作型战斗。

④ 数值护栏（防带小号）

  • 借力/助战收益随境界差衰减：境界差 ≥3 时收益减半，防「大号带小号」刷人情与默契。
  • 助战入场有每日次数上限；实时求援有全局冷却（5 分钟），防止战斗无限续命。

6.14 内功心法与修炼系统（三大资源线的修炼玩法）

玩法定位：武学不只是「技能释放」，还有「内功养成」——心法决定资源回复与被动，打坐/冥想是三层力量本源（内力/体能/灵力，见 6.12）的日常修炼入口。

① 心法槽位

  • 装备一门心法（新表 inner_minds 或复用 skill_templates + art_type=内功）：决定内力/体能/灵力三项的回复效率与专属被动（如金钟罩减伤、呼吸控制供氧、灵力亲和）。
  • 心法分级对应三层境界：基础心法（内力向）/ 科学心法（体能向）/ 玄学心法（灵力向）；心法切换有冷却（5 分钟），战斗与突破仪式中不可切换。

② 打坐与冥想

  • 打坐：安全区打坐获得双倍资源回复 + 修炼值（修炼值推动心法等级）；组队打坐（双修）效率 +20%——修炼也要「一起」（社交连接：好友/侠侣双修有额外加成）。
  • 冥想（玄学向）：消耗灵石冥想，提升悟道效率与灵力上限，是玄学篇的专属修炼节奏。
  • 离线挂机修炼见 6.17③，与打坐形成「在线主动 + 离线被动」双轨。

6.15 武学秘籍与传承（秘籍经济）

玩法定位：秘籍是武学养成的「收藏与交易」载体——获取途径多样，残页可交易，参悟需要资源，让武学本身成为可流通的社交商品。

6.16 奇遇与机缘系统（武学奇遇 / 玄学机缘）

玩法定位：奇遇是武学成长的「惊喜通道」，机缘是玄学篇稀缺性的来源——两者都由社交行为触发，落实「高阶力量的门槛是社交深度」（世界观总纲）。

① 武学奇遇

  • 触发源：逛街遇路人甲（见 8.12②）、NPC 好感达标、茶楼听书线索（见 8.10②）、随机街头事件。
  • 奇遇类型：发现秘籍、无名老者指点（技能强化）、石壁刻痕（隐藏技能）、挑战幻境（奖励修炼值）。
  • 奇遇冷却：每日奇遇上限 + 稀有度权重，防刷。

② 玄学机缘

  • 机缘事件是玄学篇晋升（61 级）与机缘令（见 6.9②）的主要来源：打听消息获得「机缘指引」（A 级情报，见 8.6）、揭榜高难任务、情谊深度达标（结义/侠侣/帮派贡献）。
  • 机缘稀有度分级：灵缘 / 仙缘 / 天缘；天缘触发全服广播（展示类社交），引动他人围观与求带。

③ 悟道任务链

61 级玄学晋升前置：多步任务链串联「打听消息 → 揭榜 → 情谊考验」三类社交行为（见 6.9①），失败不断链（从当前步续做），但会清空部分机缘进度——鼓励一次做完。

6.17 演武与修炼场所（每日修炼节奏）

玩法定位：给「练武」一个仪式化的场所与节奏——木人桩练熟练、练功房挂机、演武场切磋，各司其职。

  • 木人桩：城镇演武场内的单机练功目标，战斗获得武学熟练度（见 6.2）与少量经验；无风险、无消耗，是新技能上手与熟练度保底的场所。
  • 演武场：擂台切磋场地（见 8.5 切磋扬名、6.11 观战打赏），可设友谊赛 / 彩头赛 / 帮派内训。
  • 练功房：帮派练功房 / 家园练功桩（见 8.16②），支持离线挂机修炼（离线结算补发，呼应第 14 章）——修炼值按心法等级结算，上限 8 小时。
  • 每日修炼节奏：每日修炼时间有软上限（如 2 小时高效段，之后收益衰减 50%），防肝保健康，把「练武」从苦役变成节奏。

6.18 医术毒术与丹药（生活武学）

玩法定位：医术毒术是「生活向武学」——不直接堆战力，但决定续航、补给与对战局的影响力，是战斗经济的供给端。

① 炼丹（医术）

  • 采集：野外药材采集（资源点，见第 5 章场景）+ 集市购买（见 8.16② 摆摊经济）。
  • 配方：丹药分回血 / 回内 / 临时属性三类（对应 6.3 Buff）；高品丹药需高阶医术等级 + 稀有药材。

② 制毒（毒术）

  • 毒药可淬于暗器与兵器（见 6.7 蛇影缠身、飞蝗石），造成持续伤害 / 减益。
  • 解毒丹、抗毒心法是反制手段——毒与医互为攻防，形成「战斗前准备」的策略层。

③ 治疗定位

  • 医术技能（金创药灸等）是队伍治疗的稳定手段（见 6.11 组队角色定位），丹药则是单人续航的补充。
  • 救死扶伤声望：治疗量 / 解毒次数折算江湖声望（见 6.13③ 战斗声望口径一致）——生活武学同样通往「侠义」。

6.19 阵法与合击（多人战斗的社交内核）

玩法定位：把「组队」从「各打各的」升级为「阵法配合」——战斗不再是个人的数值叠加，而是多人协作的同步表演。这是社交元素对战斗机制最直接的改造。

  • 就位同步：队长配置阵型图，队员须在 10 秒限时内按站位就位才触发阵法——「站错位阵法失效」，真实协作而非挂机。
  • 强度随默契：阵法效果 = 基础 ×（1 + 默契等级加成，见 8.14②）；结义/侠侣成员同阵额外加成。
  • 阵法克制（呼应 6.10⑤ 机制克制的延伸）：北斗克五行、五行克三才、三才克北斗——组队博弈从「选人」扩展到「选阵」。

② 合击同步机制（深化 6.10⑥）

  • 触发：两名以上队友在 2 秒窗口内按「合击谱」顺序释放指定技能即触发合击；合击谱随关系解锁（结义技 / 情侣技 / 师徒技，见 8.7）。
  • 强度随默契：基础合击（陌生队友，无加成）→ 精妙合击（知己，+20%）→ 天衣无缝（生死之交 / 侠侣，+40%）。
  • 失败成本：错过合击窗口则进入「失衡」短暂减益——鼓励沟通而非无脑按键，把战斗节奏变成对话。

6.20 援护与战斗分工（副本协作机制）

玩法定位：高难战斗必须「分工 + 互相保护」——让协作从可选变为刚需，社交沟通成为过关的充分条件。

① 援护 / 挡刀

  • 队友可消耗情谊值（见 8.13③）替被集火队友承受 1 次伤害（挡刀）；情谊 ≥ 知己 解锁。
  • 援护成功双方得「过命交情」标记（呼应 6.13 并肩成长），触发 8.7 好感度加成；每日援护上限防互刷。

② BOSS 机制分工

  • 高难副本 BOSS 设计「分工机制」：拉怪（坦克）、打断（技能打断窗口）、解机关（场景交互）、治疗轮换——任何一环缺失团灭倒计时。
  • 分工失败惩罚作用于全队，倒逼沟通——战斗机制层面强制「必须交流」。

③ 战斗沟通工具

  • 队伍快捷信号盘（集火 / 撤退 / 求援 / 就位），低门槛传递战术意图；战术标记（场景标点）供队长布阵。
  • 队伍语音（Socket.IO 音频，可选）降低高难副本沟通成本；信号盘同时服务实时求援（见 6.11③）。

6.21 战斗中的社交对抗（恩怨 × 战斗）

玩法定位：对抗不只是数值对撞，还承载恩怨叙事——仇人战、阵前挑战、观战情报，让每一次交手都有「江湖故事」。

① 恩怨对决

  • 结仇双方（见 8.15②）交手自动触发「恩怨战」：双方情绪值提升（BUFF），胜者获复仇 / 雪耻声望，败者记录待雪。
  • 恩怨战全程可围观（助威与气势，见 6.10⑧），围观者可押彩头。

② 阵前挑战（帮战）

  • 帮战开战前双方可派代表「单挑下战书」：胜者帮派士气 +15%（全局气势），代表由帮派声望最高者担任。
  • 单挑代表即「展示类」社交动作（见 8.5 切磋扬名的帮战延伸），下战书内容全服广播。

③ 观战实时情报支援

  • 观战者（见 6.10⑧）可在战斗中通过弹幕向己方战斗者传递实时情报（目标弱点提醒 / 技能预警）。
  • 情报质量受观战者谍报等级影响（呼应 8.6）——观战从「看热闹」升级为「参与战斗准备」，围观者也成为战斗的一环。

6.22 战后社交仪式（战果的社交化）

玩法定位：战斗结束不是终点，而是新的社交起点——战果被传播、被纪念、被再战，形成「打 → 传 → 再打」循环。

① 战后互动

  • 击掌 / 致敬（双方好感度小幅提升）、「再战」约定（生成好友/再战推荐，沉淀新关系）。
  • 帮战 / 通缉战后自动开启帮派「庆功宴」或「战利品拍卖」（见 8.8 帮派宴会、第 11 章拍卖）。

② 江湖快报深化（呼应 6.11③）

  • 战报生成：胜者登「今日英雄榜」（茶楼头条，见 8.10②）；败者可发「雪耻宣言」——直接拉起恩怨战（见 6.21①）。
  • 战报可收藏 / 转发（展示类社交动作），是「被看见」的资源入口（呼应 8.16 人气值）。

③ 战败保护

  • 战败方获「重整旗鼓」Buff（1 小时 +10% 修炼效率，见 6.17），把挫败转化为成长节奏。
  • 连续战败触发「情义相助」引导（见 8.13③），防挫败流失——战败也是社交入口。

6.23 面子与羞辱（颜面的平行维度）

玩法定位：武侠重颜面——战斗胜负之外还有「面子」的输赢，让围观、羞辱、认输都有独立于血条的第二条数值线。

  • 初始 50，周结算进「面子榜」（并入排行，见第 10 章）——颜面本身是可经营、可炫耀的社交资产。

② 羞辱机制

  • 战斗中对败者「公开羞辱」（广播 + 围观必看）：羞辱者涨颜面，被羞辱者颜面大损并触发「雪耻宣言」（见 6.22②）直接拉起恩怨战（见 6.21①）。
  • 护栏：羞辱需当面（同场景）且可被拒绝（拒绝者颜面小幅损失但可反制，防止单方面霸凌）；恶意羞辱被举报核实扣信用分（见 8.15③）。

6.24 战利品分配仪式（组队收益社交化）

玩法定位：组队收益分配不是后勤问题，而是社交仪式——分得透明、分得漂亮，队伍关系更牢固；分得不公，结仇起点。

① 分配模式

  • 按贡献：DPS + 治疗 + 援护（见 6.20①）权重自动分账——引导「又输出又救场」的协作型玩法（呼应 6.13③ 战斗声望口径）。
  • 抽签（ROLL）：贵重掉落全队公开 ROLL 点，点数可见、可炫耀。
  • 队长分配 / 均分：由队长声明，分配明细入队伍日志。

② 仪式化与仲裁

  • 贵重掉落全队「过目」（展示给全队），得主可「谢队」发红包（见 8.13②）——分配本身就是社交互动。
  • 分配争议可提交 GM 仲裁（见 13.5 审计）：基于 items 快照与 combat_logs 贡献明细判定（呼应第 11 章交易仲裁），仲裁结果入失信记录（见 8.15③）。

6.25 战斗调解与仲裁（第三方说和）

玩法定位：不是每场冲突都要打到底——江湖有「说和人」，声望与关系可以终结战斗，把对抗转化为关系。

  • 说和人：声望高的第三方（帮主 / 高好感 NPC / 侠侣 / 结义兄弟）可对恩怨双方发起调解（呼应 8.15② 化解）。
  • 调解流程：双方各陈诉求（付代价 / 道歉 / 互让）→ 说和成功：双方获「不打不相识」好感（见 8.15②），失败则进入恩怨战（见 6.21①）。
  • 系统仲裁：无法说和的纠纷（劫镖 / 诈骗 / 恶意羞辱）走官府仲裁（GM 审计，见 13.5），判决执行（赔偿 / 禁言 / 封禁）入失信记录（见 8.15③）。
  • 说和收益：说和成功者获「息事宁人」声望与全服广播（展示类）——调解也是战斗之外的第二战场。

6.26 战斗对抗平衡策略（克制有循环，胜负有护栏）

玩法定位：战斗平衡不是「数值相同」——而是每种流派有克制、每种克制有代价、每场胜负不绝望。

  • 三层克制循环：基础篇 → 科学篇 → 玄学篇循环克制（10% 克制加成），同层内五行相生相克（见 6.10④）——克制形成循环，循环逼出配队与换人（社交决策，见 6.19 阵法）。
  • 境界差衰减：高境界对低境界衰减（默认每差 1 级 -2%，上限 -40%），高装等同样衰减（见 4.10⑤）——碾压被限制，切磋与协助仍有意义（带小号 / 结义互助，见 8.14）。
  • 胜负结算护栏：点到为止模式胜者收益上限（防刷）、生死斗败者保护（见 6.10⑨ 遗物由好友收敛）——输赢有代价但不致命（战败重振 Buff，见 6.22③）。
  • PVP 与 PVE 分离：PVP 数值（克制 / 衰减 / 暴击）与 PVE 数值独立配置——刷副本的强度不等于欺负人的强度。
  • 反互刷护栏：连续对刷收益递减（见 10.6 有效互动计分同思路）、观战押注上限（见 9.7③）——战斗结果被围观，刷子无处遁形。
  • 实时校验：三层流派胜率按日监控（见 13.4）——任一流派胜率跌破 40% 触发平衡公告与热修复（见 13.6 灰度流程）。

7.4 任务类型体系（任务 × 社交矩阵）

玩法定位：任务不只「杀怪收集」——本作任务类型按「是否社交」重排，社交任务占比是运营配置项（默认 40%）。

7.5 社交任务设计（把社交动作变成任务目标）

玩法定位：target_json（见 7.1）直接支持社交目标——任务给社交发指令，社交给任务供进度。

  • 社交目标类型：刺探 N 次 / 送礼 N 次 / 组队完成副本 N 次 / 帮贡 N 点 / 揭榜 N 次 / 运镖 N 次——与七大社交动作一一对应。
  • 奖励倾斜：社交任务奖励侧重声望 / 人情 / 好感度（社交货币，见 11.12）——做社交得社交，循环自洽。
  • 任务示例：每日「茶楼跑腿」（组队听书 + 送礼答谢）、「百晓生悬赏」（刺探 2 次）、「镖局帮工」（护送 1 趟）——日常即江湖生活。
  • 社交门槛：高价值任务设社交前提（需要 1 名好友 / 帮派成员 / 情报等级，见 15.3 七日引导同思路）——能力不足时，求助社交是正解。

7.6 剧情任务与社交解锁（剧情随互动推进）

玩法定位：剧情不是「自动播放」——社交动作是剧情的钥匙，剧情走向由玩家关系网络决定。

  • 社交解锁节点：主线节点需要情报达标（见 8.6）、好感度达标（见 8.7）、帮派身份（见 8.18）——不社交，剧情卡住。
  • 剧情分叉：关键剧情多分支（帮 A 还是帮 B），由角色关系（见 3.6 关系网络）与选择决定——每个玩家的剧情由自己的社交史写成。
  • 剧情见证：婚礼 / 结义 / 拜师剧情可邀请好友/帮派观礼（见证系统）——剧情是社交事件的「仪式时刻」。
  • 剧情回响：剧情选择写入记忆（见 3.6），后续 NPC 对话差异化回应——社交史即剧情史。

7.7 成就体系深化（成就的社交展示）

  • 成就墙：个人主页展示成就墙（见 8.16③ 观战主页）——成就是「我玩过什么」的履历。
  • 成就称号：成就解锁展示称号（见 8.16①）——头衔是社交名片。
  • 成就分享：达成成就可分享到频道（见 14.1）——分享动作本身计入活跃。
  • 成就等级：成就进度可视（current_value / target_value，见 7.3）——差一点就解锁，是继续社交的钩子。

7.8 任务协作与共享（任务也可以一起做）

  • 组队任务进度共享：组队时任务进度共享（击杀/收集同计）——组队是「任务加速器」。
  • 帮派任务全员进度：帮派任务全员共享进度（帮派建设，见 8.19）——一人出力、全帮受益。
  • 求助任务：任务卡关可向好友/帮派求助（求援，见 6.11① 实时求援同框架）——卡关是求助理由，求助是社交机会。
  • 师徒带教任务：师徒共同完成任务（双人教程，见 15.4）——老带新任务化。

7.9 任务经济与投放（任务控制社交节奏）

  • 社交配额：每日社交动作有配额（见 8.17 治理、10.6 有效互动同口径）——任务投放不超过配额，防刷且保真实。
  • 奖励结构：任务奖励混合货币 + 社交货币（人情/帮贡/声望，见 11.12）——经济系统喂社交。
  • 投放节奏：日常任务错峰、周常重协作、主线重剧情——避免「任务疲劳」，社交任务穿插防纯刷。
  • 运营配置：社交任务占比、配额、奖励倍率全部远程配置（见 13.2）——节奏由数据说话。

7.10 社交任务目标类型补充（战斗 / 经济 / 生态行为 → 任务）

阶段 3（2026-09-19）已实现 5 类社交动作事件推进（情报/送礼/好友/帮派/亲缘）；本节补充游戏内战斗/经济行为与业务生态行为两类目标（规划备案 2026-09-20，详见第 16 章）：

  • 生态行为：view_article / view_course / view_product / view_price / view_activity / join_activity / like / comment / purchase / distribute——业务站点行为经签名回调 POST /api/client/v1/eco/events 上报，映射推进（见 16.3/16.4）。

第 8 章 · 社交系统（核心）

本章为全手册重心。聊天、好友、帮派、邮件是基础社交设施；七大社交动作矩阵（见世界观总纲）中，情报、展示、悬赏、馈赠四类的数据底座在此落地。

8.1 聊天（chat_messages）

三频道：world 世界 / private 私聊 / guild 帮派。记录发送者、接收者（私聊）、帮派（帮派频道）、内容。世界频道是「发广告」「求助」「喊话」的场所，需配合敏感词与频率限制。

8.2 好友（friends）

好友状态机：pending 待处理 → accepted 已接受（或 blocked 拉黑）。备注（remark）、最近聊天时间。好友是送礼、私聊、组队、结义的基础关系单元。

8.3 帮派（guilds / guild_members / guild_donates）

帮派：名称唯一、帮主（leader_id）、等级、成员数、图标、帮派 Buff（全员加成，如「帮派心法」）、公告、解散时间。

成员：职位（leader 帮主 / officer 副帮主 / elite 精英 / member 成员）+ 帮贡（contribution）。

捐献：金币/钻石/物品三种类型（donate_type），获得帮贡（contribution_gained）。帮贡兑换帮派技能/资源——「情义相助」「帮派建设」社交动作的落地。

8.4 邮件（mails）

系统 / 玩家两类发件（sender_type），支持附件奖励（attachment_json）、批量发送（batch_id）、模板（template_id）、过期未领消失（expired_at）。系统邮件用于运营发奖、离线补偿；玩家邮件支撑「送礼」「侠侣书信」。

8.6 情报生态详解（刺探 / 打听 / 窃听）

玩法定位：情报是本作社交经济的第一硬通货——它同时喂给任务（剧情线索）、战斗（目标弱点）、交易（货品）三条线。

① 情报价值分级（策划建议）

等级名称来源用途
E街谈巷议逛街交流、茶楼听书日常闲聊、低价值传闻
D市井传言打听消息（百晓生）小任务线索
C可靠消息刺探成功剧情节点解锁、弱克制加成
B机密渗透 / 窃听成功关键剧情、目标弱点（破防+15%）
A绝密高谍报等级 + 高难度任务玄学机缘指引、阵营级事件

② 谍报成长曲线

  • 每次刺探产出 1 条情报 + 情报值；情报值累计提升 espionage_level（建议阈值：1-5 级每级 100，6-10 级每级 300，封顶 10 级）。
  • 刺探成功率 = 基础成功率（60%）+ 谍报等级 × 3% − 目标反侦察等级 × 3%；失败进入冷却（10 分钟）并可能暴露身份。
  • 高价值情报有保鲜期（B 级 48h、A 级 24h），过期降级或作废，防止囤积压价。

③ 情报交易市场

传闻与秘密（memories.rumors / secrets）可挂单出售（复用 trade_orders 挂单模式 + chat world 广播叫卖）。买方支付金币，成交后情报入买方记忆。防滥用：情报实名来源留痕（记忆记录卖家），贩卖假情报（伪造）会降忠诚度并触发仇人关系。

8.7 关系养成详解（结义 / 师徒 / 侠侣）

① 好感度阶段（character_relationships）

阶段好感度解锁内容
陌生 stranger0基础对话
相识 acquaintance50私聊、送礼（每日上限）
友人 friend150组队加成 +5%、切磋
知己 confidant300结义资格、共享情报、双人任务
生死之交 sworn500结拜技、互助复活、遗产继承

好感度来源：送礼（按礼物价值）、组队、助战、剧情共同经历；负面事件（背叛/拒绝求助）大幅扣减并可能降级。

② 结义（桃园结义）

  • 人数 3-8 人，成员互为知己（好感度 ≥300），于「结义亭」场景行结拜仪式（全服广播）。
  • 结拜收益：结拜技（合击技，需组队且同时在场）、属性加成 +3%、互助复活（每日限次）。
  • 结义名册写入关系表（history 记录结义事件），背叛结义（主动攻击兄弟）全服公示并降忠诚。

③ 师徒传承

  • 拜师条件：师等级 ≥ 徒 +10；行拜师礼（敬茶互动）。
  • 收益：徒经验加成 +10%、师获得师德值（师门声望，可换称号与资源）；每日师徒任务双方各得奖励。
  • 出师：徒达指定等级自动出师，双方获出师礼包，关系保留为「师徒情谊」。

④ 侠侣情缘

  • 结缘：互为知己 + 专属求缘任务（情缘副本），仪式后结为侠侣（全服广播+称号）。
  • 情侣技（双人合击）、夫妻任务（每日同游）、家园拜访互动（情谊值）。
  • 解除：需双方同意或单方强解（强解方忠诚度 -20、全服公示）。

8.8 帮派社交运营（建设 / 帮战 / 帮贡经济）

① 日常活跃

  • 帮派任务：建设（交资源）、采购（委托购买）、护送（组队运镖）三类，产出帮贡 + 帮派资金。
  • 帮派宴会：帮主开启限时宴会场景，成员聚集互动，全员获得「宴席」Buff（经验/属性加成 1h），是「帮派建设」社交动作的仪式化出口。
  • 捐献：金币/钻石/物品三类（guild_donates），捐献排行激励。

② 帮战（周常）

  • 形式：攻城 / 夺旗，战斗类型 guild_war；报名制，每周固定时段。
  • 奖励：胜方帮派资金 + 全体成员帮贡与称号，败方参与奖；帮战日志入 combat_logs。
  • 帮战是「协作类」社交动作的最高强度场景，产出帮派技能解锁材料。

③ 帮贡经济

帮贡兑换：帮派技能（永久被动）、资源包、称号、帮派商店折扣。帮派技能树由帮主配置，成员消耗帮贡学习——帮贡是帮派内社交参与度的直接计价物。

8.9 对抗社交详解（运镖 / 通缉 / 入魔猎杀）

① 镖局运镖

  • 接镖：镖局 NPC 处领取运镖任务（货物价值=押金），护送至目标场景（押运路线跨区域）。
  • 护镖：可组队护送（押运队），沿途遭遇劫镖玩家或 NPC 劫匪；劫镖点固定（设计伏击区）。
  • 结算：送达得镖银 + 声望；被劫则货物损失（押金扣除部分），劫镖者获镖银但红名 +2h（可被通缉）。
  • 定位：高收益高风险的经济与对抗混合玩法，天然制造「护送队 vs 劫镖团伙」的社交对立。

② 通缉追杀

  • 红名（PK 值/入魔/劫镖）玩家自动上榜通缉，玩家或帮派可缴纳悬赏金发起指名通缉。
  • 击杀通缉犯：得赏金（悬赏金池）+ 正义值；被击杀者入狱/掉声望。
  • 与入魔联动：hunting_target 猎杀目标即通缉榜机制之一，入魔者既是猎手也是猎物。

③ 入魔猎杀规则细化

  • 入魔后 hunting_target 指向玩家；猎杀成功可「净化」目标（恢复原名）并获正义值奖励。
  • 入魔玩家击杀目标越多，power_boost 效果越强但魔名越响亮（暴露风险↑）——形成「越强越危险」的博弈曲线。

8.10 剧情社交详解（皇榜 / 茶楼 / 庙会）

① 皇榜悬赏

  • 每日 0 点刷新悬赏任务池（击杀/护送/收集/情报四类），任意玩家可揭榜（quest 系统承载，类型=daily + 皇榜标记）。
  • 奖励：声望 + 银两 + 揭榜积分；积分月榜兑换「侠义」称号。
  • 部分高难皇榜需组队揭榜（协作入口）。

② 茶楼听书（江湖传闻场）

  • 城镇茶楼 NPC 定时「开书」：玩家落座收听，随机获得 1 条传闻（E~C 级情报）或小彩头。
  • 传闻可触发隐藏任务线（条件=情报等级 + 好感度），是「打听消息」的低门槛版。

③ 庙会集市（限时社交场景）

  • 周期性（如周末）开启限时场景，内置小游戏：猜灯谜（答题）、比武彩头（低门槛 PVP）、祈福（社交许愿墙）。
  • 产出：社交币（兑换装饰/称号）、限时道具；场景内强制可见他人（展示类社交动作的放大器）。

8.11 日常社交钩子与活跃度

  • 每日社交任务（模板化配置）：刺探 3 次、送礼 1 次、帮派任务 1 次、茶楼 1 次、组队战斗 1 次——每项产出社交积分 + 基础奖励。
  • 社交活跃度：每日社交动作累计活跃值，周结算宝箱（分档：10/30/60/100 活跃值）。
  • 社交积分经济：社交积分兑换修炼资源——科学篇「参悟券」、玄学篇「机缘令」——打通「社交 → 高阶力量」的最终闭环（呼应世界观总纲）。
  • 反挂机设计：社交动作需真实交互（对象随机/频道喊话/场景到场），限制脚本化刷活跃。

8.12 街头社交与路人甲（逛街交流系统）

玩法定位：逛街是最低门槛、最高频的社交入口——不组队、不花钱也能随时「社交」，是新手建立社交习惯的第一课。

① 路人甲 NPC 池

  • 每个城镇场景常驻 20-40 个路人甲 NPC（随机外貌/称谓/性格），行为模拟：走路、驻足、摆摊、闲聊（npc_templates 扩展 street_persona 字段）。
  • 对话池随机生成「街头话题」：天气、物价、传闻碎片、抱怨（隐藏线索）。同一 NPC 好感度越高，话越「深」。

② 路人好感与随机事件

  • 与路人甲闲聊可得「街谈巷议」（E~D 级情报，见 8.6），连续互动提升该 NPC 好感度，好感达阈值触发隐藏任务（送信/寻物/调解）。
  • 随机街头事件：碰瓷（赔钱/讲理/武力三选，不同声望变化）、乞讨（施舍得功德值）、求助（护送/寻回失物）、送信（跨城跑腿小任务）、算命（随机 buff/线索）——每个事件都是 10 秒内的轻量社交决策。

③ 逛街产出

逛街产出：街谈巷议（情报）、功德值（侠义向）、好人缘（街头声望）、偶发折扣（小贩好感给优惠）——用轻产出让逛街「有理由」。character_relationships 支持路人甲关系条目，单 NPC 每日情报产出上限，防止「刷路人只换情报」的数值漏洞。

8.13 馈赠打赏经济（红包 / 礼物 / 情义相助）

玩法定位：馈赠是情感表达与「能量流动」的通道——把玩家的感谢、炫耀、示好变成可量化的社交货币。

① 礼物价值体系

礼物档位花费好感度附加效果
心意（花/茶点）低（银两）+10表达友好
实用（丹药/材料）中（金币）+30对方可自用
贵重（秘籍/饰品）高（金币/钻石）+80全服广播「XX 赠 XX 千金」

礼物通过邮件（mails.attachment_json）送达；贵重礼物系统广播满足「展示」心理。每日送礼上限防刷（见 8.7）。

② 红包玩法

  • 世界频道发红包：定额/拼手气两类，金额走 economy 流水；抢红包者产生「人情值」（见 ③）。
  • 红包可挂主题（庆祝出师/结义/上榜），强化「社交仪式 → 话题 → 关注」链路。

③ 情义相助（求助打赏）

  • 玩家卡关可发起「情义相助」求助（战斗/任务/寻物），好友/帮派/全服响应；完成者获打赏 + 感谢值，求助者记录「欠人情」。
  • 人情值（复用关系表字段或新表 social_favors）：收到帮助 +1、帮助他人 +1 且解锁下次优先响应权；人情值影响求助排序——互帮互助者优先被看到。

8.14 组队协作系统（搭伙 / 默契 / 分配）

玩法定位：组队是协作类社交的核心容器——把「一起玩」变成机制：战斗加成、任务共享、收益分配。

① 组队流程

  • 发起：世界喊话 / 好友邀请 / 系统自动匹配（按战力与需求撮合，降低组队门槛）。
  • 角色定位：输出/坦克/治疗/辅助 四类，匹配时校验队伍构成（无奶队伍给建议）。
  • 收益共享：队伍成员共享任务进度与场景掉落，队长可设分配规则（均分/队长分配/贡献分配）。

② 默契度

  • 组队战斗累计「默契值」（新表 team_bonds 或复用 character_relationships）：组队完成副本/帮战/运镖增加；默契阶段提升组队属性加成（+1% → +8%）。
  • 默契值在结义/侠侣间额外加成（呼应 8.7 生死之交的合击技）。

③ 集合求助（守护模式）

  • PVP 中被追杀或红名围攻时可发起「守护求助」：帮派成员/好友 1 分钟内入场支援（入场瞬移冷却限制防滥用）。
  • 守护成功双方得「过命交情」标记（触发 8.7 好感度暴涨 + 人情值），失败不惩罚——保护被欺负玩家的体验，把对抗转化为协作叙事。

8.15 名声与恩怨系统（声望 / 侠义 / 恶名 / 结仇）

玩法定位：名声是玩家在江湖中的「人格标签」，恩怨让对抗有了故事，两者共同构成社交身份的公共面。

① 名声分层

维度增长来源消耗/惩罚作用
侠义值揭榜、通缉、救助、施舍滥杀/抢劫扣除NPC 好感、正义向任务、侠义称号
恶名值劫镖、入魔、恶意击杀净化/赎罪消耗通缉上榜（见 8.9）、恶人专属任务
江湖声望社交动作总量（情报/馈赠/帮贡）假情报、背叛扣除社交类任务解锁、社交榜

② 结仇寻仇

  • 结仇：被击杀/被劫镖/背叛等负面事件自动结仇（记录仇恨来源与事件），也可主动「下战书」指名结仇。
  • 寻仇：仇人上线/进入同场景推送提醒；寻仇成功（击杀）得「复仇」标记与小额奖励；被复仇方掉部分恶名（抵消通缉收益）。
  • 化解：请中间人（帮主/高好感 NPC）调解，或赠送赔罪礼；化解后仇怨转为「不打不相识」好感度（冲突变关系，叙事反转）。

③ 江湖信用分（防恶意治理）

信用分（0-100，初始 80）：被举报核实、恶意行为扣分；正常社交/完成任务缓慢回升。信用 <60 限制部分社交功能（世界频道禁言、红包禁发）；<30 进入「失信名单」公示。举报流程见 8.17。

8.16 展示与围观（称号炫耀 / 家园拜访 / 观战打赏）

玩法定位：展示类社交是「被看见」的舞台——称号、家园、战斗英姿都值得围观，围观产生人气，人气反哺社交经济。

① 称号炫耀系统

  • 称号来源：成就 / 榜单 / 帮战 / 侠侣 / 师徒 / 社交活跃；称号含全服可见特效，佩戴称号进场景自动广播。
  • 「炫耀」动作：向好友/帮派/世界推送称号卡片，收到点赞/祝福者反哺人气值（见 ③）。

② 家园拜访

  • 家园（新表 homes 或复用场景家具配置）：玩家布置家具/庭院/武馆，好友可拜访、留言、互动（坐、弹琴、比武台切磋）。
  • 拜访产出：主人获「人气值」，访客获限时 buff（茶点/练功桩）；每日拜访上限防刷。家园是「展示 + 交流 + 协作」三合一空间。

③ 观战与打赏

  • 擂台切磋（见 8.5 切磋扬名）支持观战：观众可押彩头（小额）、打赏（礼物/红包）、喝彩（表情刷屏）。
  • 人气值（并入社交积分或独立计数）：被点赞/被拜访/被打赏累计；人气榜（周更）兑换展示类道具——让「被看见」本身成为可经营的资源。

8.17 社交安全与治理（举报 / 屏蔽 / 信用分落地）

玩法定位：社交繁荣的前提是安全底线——治理不是「扣分工具」，而是让正经玩家敢于社交的护栏。

  • 举报：辱骂/骚扰/诈骗/外挂四类举报入口（聊天气泡/玩家名片/通缉榜），举报留证（消息快照 + 上下文），人工后台复核（GM 审计见 13.5）。
  • 屏蔽：拉黑后不再收到私聊/组队邀请/求助；被大量拉黑触发信用分观察。
  • 敏感词与限频：世界频道敏感词库 + 每分钟发言上限；广告软文检测（重复模板识别）自动折叠。
  • 信用分联动（承接 8.15③）：扣分明细可查（申诉入口），信用修复任务（完成 N 次助人）提供改过自新路径——治理闭环而非一刀切。
  • 时段治理：夜间时段（22:00-8:00）世界频道静音 + 关闭打赏功能，保护健康作息。

8.18 帮派组织与治理（建帮 / 职位 / 晋升）

玩法定位：帮派是「协作类」社交动作的容器——从建帮到治理，每一步都是组织化社交，帮派天然承载归属感与竞争。

① 建帮条件（社交门槛）

③ 晋升与弹劾

  • 晋升：贡献值排名 + 帮主任命；分堂主组织本堂帮务（采购 / 护送 / 情报采集，见 8.8①）。

8.21 帮派关系与外交（帮派 × 帮派社交）

玩法定位：帮派之间的关系像国家——结盟、敌对、信誉，帮派外交是「协作类 + 对抗类」社交动作的组织级形态。

  • 外交状态：友好 / 中立 / 敌对（帮主 / 副帮主管理）；敌对帮派可互相争夺资源点（见 5.7）。
  • 联谊活动：友好帮派联合宴会、友谊赛（切磋，见 8.5 帮派版）——帮派之间也有「不打不相识」。
  • 帮派信誉：外交承诺（结盟 / 互不侵犯）违约扣帮派信誉，信誉影响 NPC 好感与帮派商店折扣（见 11.5 信任经济同口径）——帮派也要讲信用。
  • 阵前挑战：帮战开战前的单挑仪式（见 6.21②）是帮派关系的高潮戏码，战书全服广播。

8.22 帮派经济深化（帮派基金 / 工资 / 分红）

玩法定位：帮派经济是「集体信任」的试炼场——资金池人人有份，贡献透明，分红公平，帮派才聚得拢人。

  • 资金池：来源 = 帮务（见 8.8①）+ 税收反哺（见 11.8）+ 帮战奖励 + 捐献（见 8.8①）。
  • 工资：按职位周薪（帮主可调），在职活跃发放——防挂机白拿，激励真参与。
  • 分红：帮战 / 资源战战利品按贡献分红（沿用 6.24 分配仪式：贡献权重公开可见）。
  • 互助基金：成员可申请无息借贷（帮贡担保，深化 8.13③ 互助），逾期扣帮贡——帮派内部的人情经济。
  • 内部拍卖：帮派产出稀有物内部流通（复用 11.7 拍卖框架），优先帮内消化——帮派是自给自足的经济圈。

9.6 签到社交化（把签到变成「一起做」）

  • 好友互赠：好友可「帮签」（每日限 1 人）、签到礼包互赠（沿用 8.13 送礼框架）——签到成为好友互动理由。
  • 组队签到：与好友 / 帮派成员同日签到有组队加成（默契加成，见 8.14② 同口径）。
  • 帮派签到：帮派全员签到率达标解锁帮派共享奖励（帮贡，见 8.22）——个人习惯反哺集体。
  • 断签保护：可用人情值（见 8.13③）兑换补签——断签是向好友求助的理由，把挫败转化为互动。

9.7 天梯活动社交化（ladder 赛季）

玩法定位：天梯是「竞技 + 展示」的社交舞台——赛季制、组队榜、观战应援，让冲榜被全服看见。

  • 赛季制：天梯（9.1 ladder）按赛季结算，赛季称号展示（见 8.16①），赛季末「全服英雄榜」茶楼播报（见 8.10②）。
  • 组队天梯：双人 / 三人天梯，默契加成（见 8.14②）——冲榜也要「搭得好」。
  • 观战与应援：天梯赛全程观战（见 6.11 观战打赏）、押彩头（见 6.21①）——高手对决是展示类高光。

排行记录（ranking_records）保存玩家昵称快照、排行数值、名次、快照时间（snapshot_at）——快照制保证榜单稳定可回溯，避免实时刷榜抖动。

10.3 榜单展示与炫耀（榜上有名即社交资产）

  • 榜墙：茶楼设榜墙（见 8.10② 英雄榜）——逛茶楼即看榜，榜是场景内容。

  • 称号联动：上榜获得展示称号（见 8.16①、4.6 套装称号同框架），称号即身份。
  • 点榜看人：点击榜单查看他人主页 / 装备（名片联动，见 5.6）——榜是「发现强者」的入口。

10.4 榜单社交互动（围观 / 应援 / 竞逐）

玩法定位：榜单不是静态名单——围观、应援、约战让榜「活」起来。

  • 围观与打赏：榜上玩家可被围观打赏（展示类，见 8.16②）——人气榜本身就是打赏量的度量。
  • 好友应援：好友可应援（点赞 / 留言，情义框架见 8.13③）——「我朋友上榜了」是社交话题。
  • 竞逐提醒：排名临近时提醒（「你距榜一仅差 N 名」）——目标感驱动挑战。
  • 榜上约战：榜上玩家可被挑战（天梯见 9.7、恩怨战见 8.15②）——「榜上对决」把排名变成实时剧情。

10.5 帮派与阵营榜（组织荣誉）

  • 帮派榜：帮派战力 / 繁荣度（见 8.19）、帮战战绩（见 8.8②）——组织层面的荣誉。

  • 快照制：按快照结算（见 10.2），规避最后一秒刷榜。
  • 行为审计：榜单数据异常预警（行为日志见 13.3、GM 审计见 13.5），异常名次复核。
  • 分榜公平：等级段分组榜（新手榜 / 高手榜）防大佬垄断——每个人都有「能上的榜」。
  • 社交榜防刷：人气 / 情义榜按「有效互动」计（打赏真实消耗、人情需双向）——社交榜防机器人互刷（治理见 8.17）。

  • 荣誉墙：纪念碑 / 玩家雕像（场景留痕，见 5.14③）——榜一可以被「供奉」在场景里。
  • 荣誉商店：荣誉积分兑换限定外观（限定框架，见 4.8）——荣誉可被看见、被收藏。
  • 身份联动：荣誉与声望（见 8.15①）、江湖身份互相印证——荣誉是社交身份的上层建筑。

第 11 章 · 交易与拍卖

交易是玩家经济与社交信任的试炼场。

11.1 摆摊交易（trade_orders）

卖家挂单：物品、数量、单价、币种（默认金币）。状态机：pending 待处理 → accepted 已接受 → completed 已完成 / cancelled 已取消。买家可下单选货，支持议价流程（accepted 阶段）。

11.2 拍卖行（auction_items）

卖家上架 → 竞价（current_bidder_id / current_price）→ 到期成交或流拍。状态：listed 在售 / bid 竞价中 / sold 已售 / expired 流拍 / cancelled 取消。

策划设计要点：绑定道具（bind_status / bind_type）禁止交易流通，保护绑定钻石经济；建议收取上架手续费与成交税，回收金币。交易纠纷仲裁依赖 items 快照（item_name 冗余存储）与流水审计。

11.3 议价与砍价（价格博弈的社交化）

玩法定位：买卖不只是价格，是江湖社交——砍价是嘴遁（见 6.10⑩），折扣是人情（见 8.7），成交是关系。

① 议价流程（深化 11.1 的 accepted 阶段）

  • 买家出价 → 摊主还价 → 双方可附言（砍价话术）；恶意压价被摊主标记，记入对方信用评价（见 8.15③）。
  • 议价次数设上限（防刷），超限自动锁定为原价成交或流单。

② 折扣加成（关系 + 颜面）

条件折扣来源
好感度 ≥ 友人−3%见 8.7
结义 / 侠侣−5%见 8.7②④
颜面值高（≥ 80）「面子价」−3%见 6.23
熟客（成交 ≥ 10 次）−2% 起累积熟客关系

③ 围观砍价

被围观时砍价成功触发「会过日子」小广播（展示类，见 8.16）——砍价本身也是社交表演；摊主亦可拒绝成交保颜面。

11.4 摆摊叫卖与逛街经济（展示类社交）

玩法定位：摆摊是「可逛的市集」——叫卖吸引人，逛街有偶遇，摊位有名气，让交易自带展示与社交。

  • 摆摊叫卖：区域广播（见 5.6 附近频道）限范围内喊话，有冷却；稀有货（秘籍 6.15 / 丹药 6.18）可加「宝光」特效吸引围观。
  • 摊主名气溢价：摊主名气（快报曝光见 6.22②、收藏数见 8.16③）带来至多 +10% 溢价——「老字号」招牌可长期经营。
  • 逛街经济：逛摊触发偶遇（见 5.6 路人甲 / 行脚商）；摊主随机上架隐藏稀有货，逛到就是赚到——逛街是低成本高回报的社交动作（见 8.12）。
  • 黄金铺位：主城摆摊街（见 5.5）分时段竞价摊位，出价高者得黄金铺位——铺位本身也是经济，竞争催生摆摊街的长期人气。

11.5 中间人与担保交易（信任经济）

玩法定位：大额交易需要「信得过的人」——担保机制把信任变成可经营的社交资产。

  • 担保资格：声望达「侠客」级（见 6.13③ 战斗声望口径）的玩家可担任中间人，收担保费 1%–3%。
  • 担保流程：买家款入系统托管 → 担保人验货 → 双方确认 → 放款；担保人违约赔担保金并扣信用分（见 8.15③），一次失信取消担保资格（入失信记录）。
  • 信誉中介：担保成功积累「信誉中介」声望；担保量上榜（见第 10 章），中间人是可长期经营的「职业」。
  • 与仲裁衔接：担保交易纠纷走官府仲裁（见 6.25），items 快照（item_name 冗余）与流水审计为证（呼应 6.24②）。

11.6 以物易物与赊账互助（关系经济）

玩法定位：不是所有交易都用金币——物物交换、赊账、代购都是「关系当钱花」的经济形态。

  • 以物易物：物品直接交换（支持「物品 + 金币」混合），双方确认即成交；争议走仲裁（见 6.25）。
  • 赊账：好友 / 帮派成员间赊账，人情值担保（见 8.13③），到期未还扣人情与信用分（见 8.15③）；帮派「互助基金」帮贡借贷（见 8.8 帮贡经济）。
  • 代购：绑定道具（见 11.2）无法直接流通，由帮派代购点以帮贡兑换（见 8.8），或好友代购消耗人情——绑定经济的社交出口。

11.7 拍卖现场社交（深化 11.2）

玩法定位：拍卖不只是竞价，是「现场感」社交——围观、挑衅、匿名，让拍卖成为面子与博弈的舞台。

  • 现场围观：拍卖开拍时同场景可围观（展示类，见 8.16③ 观战同框架），竞价过程可见；VIP 专属拍卖室（见第 12 章）。
  • 加价挑衅：竞价时可附「挑衅语」（出价 + 留言，围观可见）——竞价变成面子博弈（见 6.23 颜面）；匿名竞价可选，隐藏身份防结仇（见 8.15）。
  • 捡漏场：流拍物品进「捡漏场」（限时折扣，逛到即可捡漏，呼应 8.16② 逛街）；拍卖周榜（成交额 / 捡漏王）并入排行（见第 10 章）。

11.8 物价与税收治理（经济生态的社交治理）

玩法定位：经济要活而不乱——物价情报、税收反哺、囤积治理、黑市并存，构成有博弈深度的江湖经济生态。

  • 江湖物价指数：茶楼（见 8.10②）每日发布「物价行情」（成交均价）——物价本身是情报（见 8.6 情报生态），信息差交易是硬核玩家的盈利路径。
  • 税收反哺：成交税（见 11.2）按比例入帮派资金（帮派占产地商品，见 8.8）与系统回收；比例可远程配置（见 13.2）。
  • 囤积治理：监测异常囤积（单一玩家垄断某物品）触发「商队投放」（系统补货）或「官府收购」（价格管制）事件——反垄断由系统事件执行，不带入玩家恩怨。
  • 黑市：高税收物品走黑市（匿名交易、更高溢价，但不受仲裁保护，被骗无官方追责）——黑市是信用分（见 8.15③）与人情（见 8.13③）的试炼场，玩家只能靠关系网络避险。

11.10 跑商与跨地图贸易（信息差 + 风险）

  • 区域特产：铁矿产铁器、金原产宝石、黑森林产药材（见 6.18① 炼丹供给）——产地价低、异地图价高。
  • 信息差：茶楼物价行情（见 11.8）是盈利关键——跑商依赖情报网络（见 8.6），「先知先觉」的商人赚差价。
  • 风险：跑商路线即运镖路线（见 8.9①），可被劫镖；高收益路线高风险——商道是「胆识 + 关系」的博弈。
  • 商队协作：组队跑商（护卫，见 8.14）、帮派商队（见 8.8）——跑商是「协作类」经济动作，人脉即镖师。
  • 商帮声望：长期跑商积累「商帮声望」（与 11.5 信誉中介同框架），可解锁专属商路。

11.11 请客与社交消费（经济驱动社交）

玩法定位：花钱买「被看见」——请客、包场、仪式消费让金币流向社交，经济反哺关系。

  • 请客：茶馆请全场景喝茶（包场）、客栈请宴（沿用 8.8① 宴会框架）——请客者颜面 +（见 6.23），被请者好感 +（见 8.7）。
  • 「豪爽」标签：高频请客者获得展示类标签（见 8.16），江湖快报可报道（见 6.22②）。
  • 护栏：请客金额与频次可配置（见 13.2），冷却防刷好感。
  • 仪式消费：侠侣彩礼 / 婚礼（婚服 / 花轿 / 宴席，见 8.7④）——婚礼是社交经济的高光时刻，全场景围观（见 5.14 玩家自办活动）。

玩法定位：多种货币各司其职——硬通货流通、稀缺资源保值、社交货币计价关系，「社交货币不可交易」是铁律。

11.13 货币与经济通胀平衡策略（投放有门，回收有泵）

玩法定位：经济平衡目标一句话——投放有门、回收有泵、汇率有锚、通胀有监控。

  • 投放有门：金币只从任务 / 战斗 / 采集 / 交易等行为产出（见 11.1），活动投放限量（见 9 章活动）——每一枚金币都有来处，来处可审计（见 4.4）。
  • 回收有泵：修理（见 4.10②）、税收（见 11.8②）、拍卖佣金（见 11.7）、钻石单向换金币（见 11.12）持续抽走存量——回收速度 ≈ 投放速度，存量才稳定（建议日回收 ≥ 日投放 × 0.8）。
  • 汇率有锚：钻石 ↔ 金币汇率锚定商城兑换（长期稳定，禁止双向浮动）；社交货币（人情 / 帮贡 / 颜面）不参与汇率（见 11.12 铁律）——硬通货与社交货币两个池子，互不渗透。
  • 通胀监控指标：金币总存量 / 物价指数（见 11.8 茶楼行情）按日监控（见 13.4）——月通胀率超阈值（默认 5%）触发投放下调或回收加码（见 13.6 灰度）。
  • 资源联动：经济与资源供给联动（见 5.21 供需比值）——资源稀缺自动抬价、富余自动降价，物价是生态的体温计。

第 13 章 · 运营与数据

运营工具与数据底座，支撑「活动不停、问题可查、决策有据」。

13.1 公告（notices）

三种类型：popup 弹窗 / marquee 滚动 / mail 邮件。生效开关、排序、展示时间窗、创建人。用于版本公告、活动预告、维护通知。

13.2 远程配置（remote_configs）

键值配置，类型（string / number / boolean / json），版本号热更校验，生效开关。策划可无发版调整数值（如活动开启开关、掉落倍率、社交动作产出参数）。

13.3 行为日志（player_behavior_logs）

登录/登出/购买/升级/完成任务/PVP 六类事件 + 明细 JSON + IP。用于留存归因、功能使用分析、异常检测。

13.4 留存统计（retention_stats）

按注册队列（cohort_date）+ 统计日（stat_date）+ 周期（日/周/月）记录队列人数、留存人数、留存率。运营看板直接消费。

13.5 GM 审计（gm_operate_logs）

每次运营操作（发奖/封禁/修改）记录操作人、目标玩家、操作类型、变更前后快照（change_before / change_after）。一切运营权限操作必须留痕，支撑追责与误操作回滚。

13.6 活动运营工作台（预配置 / 灰度 / 回滚）

玩法定位：活动上线是「可编排的流水线」——预配置、灰度验证、一键回滚，让社交活动安全地高频迭代。

  • 预配置：活动模板（见 9.1）+ 远程配置（见 13.2）预发布，定时开启（status 编排：draft → published → ended）。
  • 灰度：白名单 / 小服灰度测试，行为日志（见 13.3）验证参与与异常（如社交动作产出参数是否失衡）。
  • 回滚：配置版本号回滚（见 13.2），GM 审计留痕（见 13.5）——活动事故 5 分钟内可撤销。
  • 数据看板：活动参与（见 9.2）、留存（见 13.4）实时监控——活动好坏当天可见。

13.7 玩家社区运营（反馈闭环）

玩法定位：运营不止发活动，还要「养社区」——公告互动、反馈闭环、玩家大使，让玩家参与治理与内容共建。

  • 公告互动：公告（见 13.1）支持回执 / 点赞（轻互动），热门公告可上茶楼快报（见 8.10②）。
  • 反馈通道：建议箱（游戏内提交）+ Bug 反馈（留档 GM 工单，见 13.5）——反馈闭环公开（「已采纳」标记，展示类）。
  • 玩家大使：活跃社交玩家认证「江湖大使」（展示称号，见 8.16①），组织新人带教（见 8.14 带新）——社区运营从官方走向玩家自治。
  • 社区外联：官方社区 / 直播联动（实时广播可转播，见第 14 章）——游戏外也是社交场。

13.8 社交数据分析（社交网络运营）

玩法定位：本作留存的第一指标是社交——用数据经营关系网络，把「社交」从口号变成可度量、可干预的指标。

  • 核心指标：好友关系数、组队频率、送礼密度、帮派活跃率 / 在线时长（帮派健康度，见 8.18 治理同口径）。
  • 关系图谱：图谱分析识别「社交枢纽」玩家（关系密度高者）——大使候选（见 13.7③）与流失挽回的锚点。
  • 流失预警：社交活跃骤降（组队 / 送礼 / 帮派发言减少）触发预警，早干预（推送社交召集，见 8.14① 联动）。
  • 社交漏斗：新玩家 7 日内是否建立 ≥ 1 个稳定关系（好友 / 帮派 / 结义）——社交建立率是留存的先行指标，低于阈值触发新手引导调整（见 15 章初始数值）。

13.9 GM 经济宏观看板（economy/dashboard，只读）

玩法定位：给 GM 一个只读「经济仪表盘」量化经济健康度——金总量、近 7 日产出-消耗（净通胀/净通缩）、账号资产分布（P50/P90/max/活跃数）、被 BAN/TRADE_LIMIT 惩罚账号持仓冻结量、风控累计回收额。GET /api/admin/v1/economy/dashboard，AdminGuard 保护、只读聚合、不触发任何处置动作；金额用 numeric 避免 float 误差（关联流水见 11.12、多币种审计见 4.4）。

13.10 交易结算对账（reconcile，只标记不自动动账）

玩法定位：日终对账「成交（trade_orders）/ 拍卖（auction_items, status=sold）/ 托管（escrow_agreements, released_at）/ 悬赏（bounties, acceptor_id）」四类结算与资产流水（transactions）一致性，防重复放款 / 凭空资产——结算少写或多写流水都逃不过审计。系统每日 @Cron 自动跑（前一日，SQL now() 定位），GM 可手动触发 POST /api/admin/v1/reconcile/run、结果列表 GET /api/admin/v1/reconcile/results（AdminGuard，手动触发留 gm-log）。按业务 id 反查流水，检出 MISSING_FLOW（缺流水）/ AMOUNT_MISMATCH（金额不符）/ DUPLICATE_REF（同源流水重复）三类异常，写入审计表 reconcile_results（stat_date + reconcile_type 幂等覆盖）。只标记、不自动回滚 / 补发——处置属人工决策（见 13.5 GM 审计），金额比较用 numeric/BigInt（见 4.4）。

  • 发言频率限制：各频道独立限频（全服最严），防刷屏；扩音喇叭（钻石付费，见第 12 章）可突破限频——扩音即付费社交表达。

14.5 实时互动玩法（Socket.IO 底座）

命名空间 /game 承载全部实时交互，核心事件：player.heartbeat（心跳保活）、world.enter-scene（进场景）、world.move（移动广播）、chat.send（聊天）、combat.attack（战斗指令）。

  • 场景同步：场景内广播按区域分片（见 5.6），控制消息量；实时位置让偶遇成为可能（见 5.6③）。
  • 观战数据流：围观 / 观战实时推送（见 6.11 观战打赏、9.7 天梯观战）——看得见才能打赏。
  • 战斗广播：combat 事件驱动战斗广播（见 6.11③ 助威联动）、帮战实时战况（见 8.8②）。
  • 在线状态：心跳驱动好友 / 帮派在线列表（见 8.2、8.8）——在线即社交召唤。
  • 断线重连：离线结算（offline）补发离线收益；断线好友代收（情义相助，见 8.13③）。

14.6 离线与异步社交（不实时也社交）

  • 离线私信：传音频道离线消息次日送达（限条数，防轰炸）。
  • 离线礼物与留言：送礼（见 8.7）与留言板（见 5.10③）离线可发——关系经营不断线。
  • 邮件通道：系统邮件（公告见 13.1）与玩家邮件共用投递通道，活动奖励（见第 9 章）走邮件。
  • 推送设置：免打扰时段、关键词提醒（被 @ / 被求援 / 帮派活动）——推送是「错过提醒」，不是打扰。

14.7 实时事件流（世界广播）

  • 广播分级：全服 / 场景 / 队伍三级，事件类型可配置开关（见 13.2），运营控制噪音。
  • 世界事件直播：世界 BOSS 开战（见 5.9②）、商队启程（见 11.10）、通缉播报（见 8.9②）——事件即流量，直播即召集。
  • 江湖快报：战斗快报 / 今日英雄榜（见 6.22②、8.10②）定时推送——世界广播是社交话题的制造机。
  • 场景氛围播报：昼夜 / 天气 / 节庆变化播报（见 5.12）——世界是「活」的，聊天跟着世界走。

14.8 频道内互动玩法（聊天本身是玩法）

玩法定位：频道不只是通讯工具——红包、签到、活动让「聊天」本身成为可玩的社交场景。

  • 频道红包：全服 / 帮派 / 队伍红包（见 4.7 红包道具）——发红包是频道的「高光时刻」，抢红包是共同的期待。
  • 频道签到：在世界频道发言打卡（承接 9.6 签到）——每日第一声招呼也是活跃指标。
  • 频道活动：运营在频道发起活动（答题 / 接龙 / 彩蛋口令，配置见 13.2）——频道活动让闲聊天变成参与感。
  • 频道幸运星：随机抽选活跃发言者发小礼（防刷：按有效发言计，见 10.6 同口径）——鼓励说话的软激励。

14.9 江湖热搜与话题广场（世界频道是舆论场）

玩法定位：世界频道沉淀为「舆论场」——热搜、话题、名人讨论让聊天内容本身成为社交资产。

  • 江湖热搜：按提及量 / 讨论热度生成热搜榜（玩家昵称 / 事件 / 道具，见 10 章排行框架）——上热搜是玩家自发的社交荣誉。
  • 话题标签：发言可带话题（#新服 #收徒 #求组），话题页聚合讨论——找同好、找组织的入口。
  • 名人效应：榜上玩家（见 10.3）发言有标识（金色昵称）——强者发言自带流量，形成「大佬带话题」生态。
  • 舆论治理：热搜异常（刷量 / 抹黑）纳入治理（见 14.4 举报闭环、8.17 仲裁）——舆论场也要有秩序。

14.10 语音与陪伴社交（声音是有温度的）

  • 队伍语音：队伍频道实时语音（协作指挥，见 6.20③ 信号盘同口径）——组队体验从打字升级为「并肩说话」。
  • 语音房：茶馆语音房（公共房间，见 8.10② 茶楼场景）——挂机听书、聊天陪伴，房间即社交场。
  • 陪伴场景：语音房与场景联动（围篝火夜话见 5.10②）——声音 + 场景营造「在场感」。
  • 语音治理：语音举报留证（转写存档，见 14.4 治理同框架）——声音也要守规矩。

14.11 频道文化与公约（社区自治）

  • 频道等级与称号：频道发言贡献积累频道等级（称号展示，见 8.16①）——「常驻客」是身份。
  • 帮派频道文化：帮派频道可自定义口号 / 欢迎语（帮规，见 8.18）——频道即帮派门面。
  • 频道公约：公共频道公约（禁止刷屏 / 引战）由玩家投票修订（社区自治，见 13.7）——规则共建。
  • 老带新频道：新手频道常驻老玩家答疑（带新奖励，见 15.4 双人教程、13.7③ 玩家大使）——频道是最好的新手村。

14.12 智能引导与客服介入（聊天里有「人」）

  • 引导 NPC：频道内引导机器人（NPC 形象）回复常见问题（新手引导，见 15 章）——提问即引导。
  • 智能客服：投诉 / 纠纷关键词触发客服流程（举报留证，见 8.17）——频道内闭环处理。
  • 人工介入：严重纠纷转人工（GM 仲裁权，见 2.7）——智能在前、人工兜底。
  • 广播公告：客服介入结果在频道公告（见 13.1 公告通道）——处理过程公开，建立信任。

15.1 新手引导总纲（引导哲学）

16.1 生态联动总览

  • 定位：业务站点（www.joho.cn 文章 / v.joho.cn 课程 / www.youshop.cn 商品 / zhao-point 活动）的浏览、查看价格、报名、成交、分销、点赞、评论等真实行为，经业务插件回调上报 game-server，推进游戏内社交任务进度。
  • 身份打通：SSO 直接登录游戏（zhao-sso 标准 OAuth2，app_code=game）——玩家在游戏内以 SSO 会话建档，auth_accounts 记录 sso_id 唯一映射，行为回调按 sso_id 定位玩家。
  • 数据通路：行为在业务系统本地发生最可信 → 业务插件钩子（fire-and-forget POST + HMAC 签名）→ game-server POST /api/client/v1/eco/events → 签名/防重放校验 → EventBus ECO_ACTION → 任务监听器推进。

16.2 SSO 直接登录流程

步骤动作
1游戏前端 GET /api/client/v1/auth/sso/login → 302 至 zhao-sso authorize?app_code=game&redirect_uri={游戏回调}&response_type=code
2SSO 授权 → 302 回 GET /api/client/v1/auth/sso/callback?code=xxx
3game-server 用 code 调 zhao-sso exchange-token（回调一致性由 zhao-sso 白名单校验）→ { ssoId, username }
4auth_accounts 按 sso_id 查 → 有则签发游戏 token；无则自动建档（accountType=SSO，密码随机不可密码登录；用户名冲突加后缀）→ 建 players 行 → 签发 token
  • 表变更：auth_accounts += sso_id varchar(64) unique nullable / sso_provider varchar(32)（只加列）。
  • 兼容：既有 NORMAL 用户名密码登录保留，SSO 账号与 NORMAL 账号并存不迁移。
  • 错误码：SSO_AUTH_FAILED(91605) 换码失败 / SSO_ACCOUNT_EXISTS(91606) 用户名冲突。

16.3 生态行为上报契约

  • 接口：POST /api/client/v1/eco/events（业务插件回调，非玩家直调）。
  • 请求头：X-Eco-Sign = hmac_sha256(sharedSecret, body + "|" + timestamp)；X-Eco-Ts unix 秒；密钥走环境变量 ECO_SHARED_SECRET。
  • 请求体：{ "action": "view_article", "scope": "joho", "ssoId": "12", "targetId": "1024", "extra": {} }。
  • 校验管线：时间戳窗口 ±300s → HMAC 签名比对 → Redis 防重放（eco:evt:{hash} SET NX EX 300）→ action 白名单 → sso_id 定位玩家（无对应玩家静默 200，业务侧无需感知）→ 发 ECO_ACTION。
  • 错误码：ECO_SIGN_INVALID(91601) / ECO_REPLAY(91602) / ECO_SSO_NOT_BOUND(91603 静默) / ECO_UNKNOWN_ACTION(91604)。

16.7 防刷与风控

  • 签名防伪造：HMAC-SHA256 + 时间戳窗口 ±300s + Redis 防重放（一次性事件哈希）。
  • 浏览类日上限：生态浏览类任务进度每日最多计入 10 次（Redis eco:daily:{playerId}:{targetType} EX 86400），防脚本批量刷浏览任务。
  • 真实行为锚点：成交/报名/分销以业务侧真实记录创建处触发（enrollment/signup/订单），不可凭空构造。
  • 业务侧故障隔离：钩子失败不影响业务主流程（fire-and-forget + 静默）。

16.10 互刷 / 洗分检测风控（risk 模块）

玩法定位：把「跨账号价值转移」归一化后按时间窗检测对敲 / 失衡 / 异动三类风险信号，给账号累计风险分，供 GM 预警与处置——防洗金打金、礼物互刷、拍卖对倒洗价值。

  • 流水归一化：risk_wash_flows 统一摄入跨账号转移（成交 / 礼物 / 拍卖结算 / 托管放款 escrow / 悬赏奖励 bounty），flow_class 区分 TRANSFER（参与回环 / 失衡检测）与 PAYOUT（仅供价值异动观察）；refId 幂等，各源高水位键自动推进。
  • 三类信号：回环对敲（双向净额近乎抵消但总量大）、失衡赠与（单向大额无回流）、价值异动（同资产对倒 / 价格偏离近期成交基准 >n× 或频次暴涨）。
  • 账号评分：risk_account_scores 累计 0–100，评级正常 / 关注（≥watch_score）/ 高危（≥high_score）；每 10 分钟定时批扫。
  • 实时拦截：高危账号经 RiskGateService 实时限制——拍卖起拍价超 auction_value_cap 拒上架（93202）、单日送礼 / 转账累计超限拒执行（93201）。
  • 风控回收闭环：GM 对线索出回收提案（净差额）→ 确认对净收款方真实扣款（EconomyService 扣 GOLD，流水号留 economy_ref_id，快照存动账前余额）并落 risk_recover_records 台账、切断线索（open→frozen）→ 可按流水号精确回滚；高危线索可联动既有惩罚封禁 / 交易封锁（POST cases/:id/lock，复用 PenaltyLevel）。
  • 只读回放校准阈值：支持 GM 按 [since, until] 时段 + configOverrides（仅 risk.* 检测阈值键，非法 92901）对 risk_wash_flows 历史重放三类检测，返回命中清单 hitAccounts 与分数档位分布 scoreBuckets，供运营量化「阈值配到某值会命中多少人」，读多线不落库不处置。
  • 身份聚类信号（一人多号）：定时从登录日志 / 账号数据聚合身份邻接（窗口内同 IP、同设备、SSO 同源，写入 risk_identity_links 无向去重幂等），强信号即为「同人多号」特征，其身份分（分量 2 个账号基础分、≥3 更高分）并入 risk_account_scores 且不越 score_cap；GM 经 GET identity/player/:playerId 只读查看该玩家的身份图谱（peer 关联 + 簇规模）。

  4. 验证 /api/docs 与健康接口

C.3 安全与备份

  • 数据库凭据与 JWT_SECRET 仅存 .env.prod，禁止入 git
  • 管理员初始密码首登后修改；admin_passwd 类数据库管理密码用强随机
  • 定期 pg_dump 备份 game_server 库

C.4 监控与告警

  • 健康检查：进程存活 + 健康接口轮询（systemd 自动拉起），DB / Redis 连通性监控。
  • 指标监控：CPU / 内存 / 连接数（1G 内存服务器尤其关注 OOM，见 15 章部署约束），Socket.IO 在线数。
  • 业务告警：交易 / 帮贡 / 情报产出异常波动（防刷预警，见 10.6、13.3 行为日志）——社交经济异常当天可见。
  • 日志聚合：应用日志 + gm_operate_logs（见 13.5）统一归档，支撑排查与追责。

C.5 数据备份与恢复

  • 定期备份：pg_dump 定时（每日），备份文件异地留存（服务器为 1G 小盘，备份转存本机）。
  • 恢复演练：季度恢复演练——社交数据（好友 / 帮派 / 好感度）不可重建，备份是唯一保险。
  • 配置备份：远程配置（见 13.2）版本化导出，随代码入库。

C.6 版本发布与回滚

  • 发布流程：本地构建 → 同步 .env.prod → scp 产物 → 重启 → 验证 /api/docs 与健康接口（见 C.2）。
  • 灰度：大版本白名单灰度（远程配置开关，见 13.2），行为日志验证（见 13.3）。
  • 回滚：保留上一版产物 + 配置版本回滚（见 13.6）；数据库变更遵循「只加宽不缩容」原则（生产列精度教训）。

C.7 安全加固清单

  • SSH 仅密钥登录（关闭密码）、防火墙仅开放 22 / 80 / 443（安全组白名单）。
  • 接口限流与防注入（NestJS 校验管道，防 SQL / 命令注入，见 13.3 行为日志留痕）。
  • 密钥轮换：JWT_SECRET / Redis 密码定期轮换，token_version 全员下线能力（见 2.2）配合。
  • 管理后台双因素（admin_users，见 2.3）——GM 权限是攻防焦点。
