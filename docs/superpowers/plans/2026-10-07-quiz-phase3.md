# quiz 接入层（阶段 3）实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 独立客户端凭证鉴权（apps.api_key → appCode）+ quiz 玩家 API 接真实 appCode + 对话 action 扩展（`quiz`/`assess`）+ game-client API 封装与 QuizPanel。**依据 spec:** `docs/superpowers/specs/2026-10-07-content-sharing-design.md` §4.3/§5/§7（阶段 3 行）。

**Architecture:** 请求头 `x-api-key` → `AppScopeGuard` 查 apps 表（isActive）→ `req.appCode`，缺失时服务端常量 `DEFAULT_APP_CODE='main'`（appCode 永不信任前端）；对话 action 由 `dialogue.appScope` 推导 quiz 可见域（common 卷传 null，自有卷传自身 code）；执行结果以可选 `quiz` 字段附在 DialogueView 回传客户端。

**Tech Stack:** NestJS 11 + TypeORM + PostgreSQL 16 + Jest/ts-jest + Laya（game-client）。

- [ ] **Step 1.2: AppsService（查库 + appCode 解析三态）**

```ts
// src/modules/apps/apps.service.ts
@Injectable()
export class AppsService {
  constructor(@InjectRepository(App) private readonly appRepo: Repository<App>) {}

  /** 凭证 → app；无效/停用/空凭证返回 null（表极小，不加缓存） */
  async findByApiKey(apiKey: string): Promise<App | null> {
    if (!apiKey || apiKey.trim() === '') return null;
    return this.appRepo.findOne({ where: { apiKey: apiKey.trim(), isActive: true } });
  }

  /**
   * appCode 解析唯一出口（spec §4.3：不信任前端）：
   * - 无凭证 → DEFAULT_APP_CODE（主游戏，服务端常量）
   * - 凭证有效 → 对应 app.code
   * - 凭证无效 → APP_API_KEY_INVALID
   */
  async resolveAppCode(headerValue: string | undefined | null): Promise<string> {
    if (headerValue === undefined || headerValue === null || headerValue.trim() === '') {
      return DEFAULT_APP_CODE;
    }
    const app = await this.findByApiKey(headerValue);
    if (!app) {
      throw new GameException(ErrorCodes.APP_API_KEY_INVALID, '接入凭证无效');
    }
    return app.code;
  }
}
```

```ts
// src/modules/apps/app-scope.guard.ts —— 可选 guard：仅挂到需要 appCode 的玩家侧 controller
@Injectable()
export class AppScopeGuard implements CanActivate {
  constructor(private readonly appsService: AppsService) {}
  async canActivate(context: ExecutionContext): Promise<boolean> {
    const request = context.switchToHttp().getRequest();
    request.appCode = await this.appsService.resolveAppCode(request.headers['x-api-key']);
    return true;
  }
}

export const CurrentAppCode = createParamDecorator(
  (data: unknown, ctx: ExecutionContext): string => {
    const request = ctx.switchToHttp().getRequest();
    return request.appCode as string;
  },
);
```

```ts
/** 对话 assess 入口：复用本人未完成会话（续答指针），否则新建（普通 start 保持原语义不变） */
async startOrResume(playerId: string, code: string, appCode: string | null) {
  const assessment = <同 start 的 scope 查询>;
  if (!assessment) throw ... QUIZ_ASSESSMENT_NOT_FOUND;
  const existing = await this.sessionRepo.findOne({
    where: { playerId, assessmentId: assessment.id, status: QuizSessionStatus.IN_PROGRESS },
    order: { startedAt: 'DESC' },
  });
  if (existing) {
    if (existing.currentQuestionId) {
      const question = await this.questionRepo.findOne({ where: { id: existing.currentQuestionId } });
      if (question) return { sessionId: existing.id, question: this.sanitizeQuestion(question), resumed: true };
    }
    throw new GameException(ErrorCodes.QUIZ_SESSION_FINISHED, '会话已完成'); // 指针为空的防御分支
  }
  return { ...(await this.start(playerId, code, appCode)), resumed: false };
}
```
