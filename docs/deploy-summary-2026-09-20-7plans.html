修复的 Bug

#位置症状根因修复
1 risk/risk-wash.service.ts → lock() 500 POST /risk/cases/:id/lock 返回 90004 Internal server error QueryFailedError: invalid input syntax for type bigint: "admin" —— lock 把 admin.username（"admin"）传给了 logOperation.adminId（bigint 列）。applyPenalty 需要 username 字符串、gm_operate_logs.adminId 需要数字，单一 operator 参数语义冲突。 lock 签名拆分为 lock(caseId, adminId, operator, level, reason)，控制器改传 admin.adminId；applyPenalty 仍用 username。与 P5 reconcile 同类的整改（高频共因）
2 多处：`reconcile-admin.controller.ts` / `risk-admin.controller.ts`（上一提交冒烟期） 500 操作审计日志写入失败 invalid input syntax for type bigint: "admin" logOperation({ adminId: admin.username }) 类型不匹配（username 字符串 → bigint adminId） 改用数值字段 admin.adminId 写入 gm_operate_logs.adminId
3 `realm/dto/cultivate.dto.ts` / `explore/dto/resolve-encounter.dto.ts` 400 property amount should not exist 入参 DTO 缺少校验装饰器，class-transformer 宽松反序列化导致校验失败 补 @IsInt() @Min(1) 校验
4 `explore/entities/encounter-template.entity.ts` / `realm/entities/realm-template.entity.ts` 500 syntax error at or near '[' JSONB 字段默认值写成 default: []，TypeORM 未序列化为合法 JSON 改为字符串 default: '[]' / '{}'
5 冒烟脚本 `smoke-stage5b.sh` 角色名超长 / 缺角色创建 测试用例失败（非应用 bug） 自动生成名 >16 字符被拒；境界用例缺前置角色 截断名称（tail -c 8）、补角色创建步骤
Bug 1 为本次部署验证环节「上线后抓到的真实缺陷」，修复后重新构建部署，单测 10/10 通过。
